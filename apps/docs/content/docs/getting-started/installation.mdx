## Download StartupBot

The [download page](https://startupbot-internal-preview.merrytoucan4.chatgpt.site/download/) lists macOS installers for Apple Silicon and Intel, Windows installers for x64 and ARM64, Android APKs, and iOS Simulator builds for Xcode. The macOS internal preview is ad-hoc signed and the Windows preview is unsigned.

## Install an agent CLI

StartupBot needs at least one supported agent engine installed and signed in. Claude and Codex are the most common starting points.

1. Install the CLI from its official provider.
2. Run it once in a terminal and complete sign-in.
3. Restart StartupBot.
4. Open the model picker. Available engines appear normally; unavailable engines explain what is missing.

See [Agent engines](../providers/index.mdx) for the complete list and explicit path overrides.

## Build from source

Requirements: Node.js 24 or newer, pnpm 10.33.0, and at least one authenticated agent CLI.

```bash
git clone https://github.com/tigerthong1102/MoonBot.git
cd MoonBot
corepack enable
pnpm install --frozen-lockfile
```

Run the harness, web UI, and Electron shell in separate terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

## Where data lives

StartupBot stores its application data under `~/.startupbot`. Electron window and browser data use the normal per-platform application data directory.
