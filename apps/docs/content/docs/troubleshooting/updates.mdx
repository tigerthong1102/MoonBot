The internal preview uses manual updates. Download the installer for your platform from the [StartupBot download page](https://startupbot-internal-preview.merrytoucan4.chatgpt.site/download/), quit StartupBot, and install the new copy. Your conversations and settings live in the StartupBot data directory.

## Report an installation problem

Include the platform, processor, installer version and the message shown. Review diagnostics before sharing them with [StartupBot support](https://github.com/tigerthong1102/MoonBot/blob/main/docs/startupbot/support.md).
