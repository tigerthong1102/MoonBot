# StartupBot license audit (initial)

The upstream root LICENSE is Apache-2.0; retain LICENSE, NOTICE and applicable third-party notices. Apache-2.0 does not grant trademark rights. LICENSING.md identifies the upstream names and mascot as trademarks.

The upstream enterprise directory has a separate license prohibiting redistribution without an agreement. It is removed from this branch's current tree, but remains in Git history and in the existing public fork. Removing files in a new commit does not remove historical access. Resolve the distribution and history issue with the rights holder and appropriate legal advice before publishing this branch or distributing artifacts; do not rewrite history automatically.

This is an initial inventory, not clearance of every dependency, asset, native app, or hosted service. Packaging and hosted authentication require verification with the enterprise directory absent. Preserve fail-closed hosted sign-in.
