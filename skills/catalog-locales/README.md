# StartupBot skill guide translations

These localized views cover the instructions in the 61 bundled `SKILL.md` files. StartupBot created the translations using machine translation and edited the shared safety guidance. Shell commands, source code examples, and referenced files are kept verbatim. English uses the original instructions except for the two Chengfeng skills, which include English translations of their Chinese instructions.

For each translated guide, the file name identifies the original in `../catalog/<name>/SKILL.md`. The original package's Apache-2.0 license, attribution, upstream notices, and pinned source accompany the translations in `../catalog/<name>/`.

The catalog records the hash of the original text the translations were made from. The app checks that the skill being viewed matches the packaged original before displaying a translation. The original remains available in the guide viewer and is the file used by the bot.
