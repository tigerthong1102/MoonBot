# 使用經批准的 Apify 來源研究產品清單和評論

使用配置的唯讀連線和公共或授權來源。僅收集請求的欄位。記錄清單 URL、貨幣、顯示價格和日期。單獨的運輸、增值稅和促銷。總結沒有客戶識別碼的評論模式。
## 研究流程

確認電商平台、搜尋詞或公開商品 URL、所需欄位、國家及結果數量限制。透過已設定的 Apify 連線查找 Actor，選擇前檢查輸入結構、價格與文件所述的涵蓋範圍。公開探索工具無須存取帳戶即可列出 Actor 和文件。執行 Actor 需要獲授權的 Apify 帳戶，可能消耗額度或產生費用。付費執行前確認預算，並在服務支援時設定費用上限。

先從小樣本開始。盡可能取得商品名稱、來源 URL、觀察價格、幣別、庫存狀態及時間。等待執行完成並檢查結果資料集；執行成功仍可能沒有商品或缺少欄位。區分缺失值與零，保留平台和賣家背景，並說明觀察時間及限制。比較時，僅在取得匯率與日期時換算幣別；來源允許時分別列出運費、促銷及稅費。

官方遠端 Apify MCP 伺服器支援公開探索，以及透過 OAuth 存取已驗證帳戶。使用現有已設定的連線；若沒有，請說明需要何種連線。切勿將 API 令牌放入聊天訊息或 URL。使用者應透過應用程式的連線流程授權。
