# 使用授權的位元組跳動語音連接器產生旁白

使用現有的位元組跳動 TTS 連線。確認文字、語音選擇和音訊格式。合成音頻，將其保存在任務工作區中，並檢查持續時間和聲音品質。僅使用使用者有權使用的聲音。

如果尚未連接 ByteDance，請說明該服務需要個別開通且可能收費；不要聲稱聊天訂閱已包含此服務。若使用者同意採用其他語音供應商且使用 Mac，可提供系統語音合成作為本機替代方案。使用 `say -v '?'` 列出可用聲音，選擇符合所需語言的已安裝聲音，再以 `say -v VOICE -f INPUT_TEXT_FILE -o OUTPUT.aiff` 寫入新的 `.aiff` 檔案。使用工作專用文字檔或標準輸入，避免私人文字留在 shell 指令歷史中。檢查輸出檔案存在、長度大於零且聲音清晰。請明確說明這是 macOS 聲音，不是 ByteDance 聲音；品質與可用聲音因電腦而異。其他平台或所需聲音不可用時，請說明缺少的條件，不要聲稱合成成功。
