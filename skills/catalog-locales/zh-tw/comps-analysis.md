## ⚠️ 關鍵：公式優於硬編碼 + 逐步驗證

**環境 — Office JS 與 Python：**
- **如果在 Excel 內部運作（Office 外掛程式/Office JS）：** 直接使用 Office JS (`Excel.run(async (context) => {...})`)。透過`range.formulas = [["=E7/C7"]]`而不是`range.values`來寫公式。無需單獨的重新計算步驟 — Excel 會自行處理。使用 `range.format.*` 作為顏色/字體。
- **如果產生獨立的 .xlsx 檔案：** 使用 Python/openpyxl。寫入`cell.value = "=E7/C7"`（公式字串）。
- 無論哪種方式，原則都是相同的——只需翻譯 API 呼叫即可。
- **Office JS 合併儲存格陷阱：** 不要呼叫 `.merge()`，然後在合併範圍上設定 `.values`（拋出 `InvalidArgument` - 範圍仍報告其合併前尺寸）。而是將值單獨寫入左上角的儲存格，然後合併+格式化整個範圍：
  ```js
  ws.getRange("A1").values = [["TECHNOLOGY — COMPARABLE COMPANY ANALYSIS"]];
  const hdr = ws.getRange("A1:H1");
  hdr.merge();
  hdr.format.fill.color = "#1F4E79";
  hdr.format.font.color = "#FFFFFF";
  hdr.format.font.bold = true;
  ```

**公式，而非硬編碼：**
- 每個派生值（保證金、倍數、統計量）必須是引用輸入儲存格的 Excel 公式 — 絕不能是貼上到的預先計算的數字
- 使用Python/openpyxl建立工作表時：寫`cell.value = "=E7/C7"`（公式字串），而不是`cell.value = 0.687`（計算結果）
- 唯一的硬編碼值應該是原始輸入資料（收入、EBITDA、股價等）——並且每個資料都會有一個帶有其來源的儲存格註釋
- 原因：當輸入改變時，模型必須自動更新。硬編碼邊距是一個等待發生的無聲錯誤。

**與使用者逐步驗證：**
- 設定結構後→在填滿資料之前向使用者顯示標題佈局
- 輸入原始輸入後 → 向使用者顯示輸入區塊並在建立公式之前確認來源/週期
- 建立營運指標公式後→顯示計算出的利潤並在進行評估前與使用者進行健全性檢查
- 建立估值倍數後 → 在添加統計數據之前顯示倍數並確認它們看起來合理
- 不要從頭到尾建立整個工作表，然後將其呈現 - 通過確認每個部分來儘早發現錯誤

## 第 2 節：營運統計與財務指標

### 核心專欄（從這些開始）
1. **公司** - 格式一致的名稱
2. **收入** - 規模指標（可以是 LTM、季度或年度，取決於具體情況）
3. **收入成長** - 年比百分比變化
4. **毛利** - 收入減去銷售成本
5. **毛利率** - 毛利率/收入（基本獲利能力）
6. **EBITDA** - 息稅折舊攤提前利潤
7. **EBITDA 利潤率** - EBITDA/收入（營運效率）

### 可選添加（根據行業/用途選擇）
- **季度與 LTM** - 如果季節性很重要，則包括兩者
- **自由現金流** - 適用於資本密集或 SaaS 業務
- **FCF 利潤** - FCF/收入（現金產生效率）
- **淨利** - 對於成熟、有利潤的公司
- **營業收入** - 適用於 D&A 不同的企業
- **資本支出指標** - 適用於重資產行業
- **40 法則** - 專門針對 SaaS（成長 % + 利潤 %）
- **FCF 轉換** - 用於收益分析品質（進階）

### 公式範例（以第 7 行為例）
```excel
// Core ratios - these are always calculated
Gross Margin (F7): =E7/C7
EBITDA Margin (H7): =G7/C7

// Optional ratios - include if relevant
FCF Margin: =[FCF]/[Revenue]
Net Margin: =[Net Income]/[Revenue]
Rule of 40: =[Growth %]+[FCF Margin %]
```

**黃金法則：** 每個比率都應該是[某物]/[收入]或[某物]/[此表中的某物]。保持簡單。

### 統計區塊（公司資料之後）

**關鍵：為所有可比較指標（比率、利潤、成長率、倍數）加入統計公式。 **

```
[Leave one blank row for visual separation]
- Maximum: =MAX(B7:B9)
- 75th Percentile: =QUARTILE(B7:B9,3)
- Median: =MEDIAN(B7:B9)
- 25th Percentile: =QUARTILE(B7:B9,1)
- Minimum: =MIN(B7:B9)
```

**需要統計資訊的欄位（可比較指標）：**
- 營收成長率 %、毛利率 %、EBITDA 利潤率 %、每股盈餘
- EV/收入、EV/EBITDA、本益比、股息率、貝塔值

**不需要統計資訊的欄位（大小指標）：**
- 營收、EBITDA、淨利（絕對規模因公司規模而異）
- 市值、企業價值（不同規模的公司之間不具可比性）

**附註：** 在公司資料和統計行之間加上一個空白行，以便視覺上分隔。不要新增「部門統計資料」或「估值統計資料」標題行。

**為什麼四分位數很重要：** 它們顯示分佈，而不僅僅是平均值。 75% 的倍數告訴您「優質」公司的交易價格。

## 第 3 節：估值倍數與投資指標

### 核心估值列（從這些開始）
1. **公司** - 與營運部門相同的訂單
2. **市值** - 當前市場估值
3. **企業價值** - 市值±淨債務/現金
4. **EV/收入** - 每美元銷售額的市場支付多少
5. **EV/EBITDA** - 每美元收益市場支付多少
6. **本益比** - 相對於淨利的價格

### 可選的評估指標（根據上下文選擇）
- **FCF 收益率** - FCF/市值（用於以現金為重點的分析）
- **PEG 比率** - 本益比/成長率（針對成長型公司）
- **價格/帳面** - 市場價值與帳面價值（對於重資產企業）
- **ROE/ROA** - 回報指標（用於獲利能力比較）
- **收入/EBITDA CAGR** - 歷史成長率（用於趨勢分析）
- **資產週轉率** - 收入/資產（用於營運效率）
- **債務/權益** - 槓桿（用於資本結構分析）

**關鍵原則：** 包括對您的行業重要的 3-5 個核心倍數。不要僅僅因為可以就包含所有可能的指標。

### 公式範例
```excel
// Core multiples - always include these
EV/Revenue: =[Enterprise Value]/[LTM Revenue]
EV/EBITDA: =[Enterprise Value]/[LTM EBITDA]
P/E Ratio: =[Market Cap]/[Net Income]

// Optional multiples - include if data available
FCF Yield: =[LTM FCF]/[Market Cap]
PEG Ratio: =[P/E]/[Growth Rate %]
```

### 交叉引用規則
**關鍵：** 估值倍數必須參考營運指標部分。切勿兩次輸入相同的原始資料。如果收入在 C7 中，則 EV/收入公式應參考 C7。

### 統計區塊
與操作部分的結構相同：每個指標的最大值、第 75 個、中位數、第 25 個、最小值。新增一個空白行，以便在公司資料和統計資料之間進行視覺分隔。不要新增“評估統計”標題行。

## 第 6 節：最佳實務與品質檢查

### 開始之前
1. **定義同業群體** - 公司必須具有真正的可比較性（相似的商業模式、規模、地理位置）
2. **選擇正確的時期** - LTM 平滑季節性；季度顯示趨勢
3. **預先標準化單位** - 數百萬與數十億的決定影響一切
4. **地圖資料來源** - 知道每個數字來自哪裡

### 當你建構時
1. **先輸入所有原始資料** - 在編寫公式之前完成藍色文本
2. **將儲存格註解新增至所有硬式編碼輸入** - 右鍵點選儲存格 → 插入註解 → 文件來源或假設

   **對於來源數據，請準確註明其來源：**
   - 範例：“彭博終端機 - MSFT Equity DES，於 2024 年 10 月 2 日訪問”
   - 範例：“2024 年第 4 季 10-K 歸檔，第 42 頁，行項目“總收入””
   - 範例：“截至 2024 年 10 月 2 日的 FactSet 共識估計”
   - **盡可能包含超連結**：右鍵點選儲存格 → 連結 → 將 URL 貼到 SEC 歸檔、資料來源或報告

   **對於假設，請解釋推理：**
   - 範例：“根據同業中位數假設 EBITDA 利潤率為 15%，公司未揭露”
   - 例如：“估計企業價值為市值 + 5000 萬美元淨債務（來自第三季度的資產負債表，第四季度尚未提供）”
   - 範例：“基於 3.45 美元的街頭共識 EPS 的遠期本益比（12 位分析師的平均預測）”

   **為什麼這很重要**：實現審計追蹤、數據驗證、假設透明度和未來更新
3. **逐行建立公式** - 在繼續之前測試每個計算
4. **對標題使用絕對引用** - $C$6 鎖定標題行
5. **格式一致** - 百分比為百分比，而不是小數
6. **新增條件格式** - 自動反白顯示異常值

### 健全性檢查
- **利潤率測試**：毛利率 > EBITDA 利潤率 > 淨利潤率（根據定義始終為真）
- **多重合理性**：
  - EV/收入：通常為 0.5-20 倍（因行業而異）
  - EV/EBITDA：通常為 8-25 倍（各行業相當一致）
  - 本益比：通常為 10-50 倍（取決於成長率）
- **成長與倍數相關性**：較高的成長通常意味著較高的倍數
- **規模效率權衡**：較大的公司通常有較好的利潤（規模經濟）

### 要避免的常見錯誤
❌ 在公式中混合市值和企業價值
❌ 使用不同的時間段作為分子和分母（LTM 與季度）
❌ 將數位硬編碼到公式中而不是儲存格引用中
❌ **硬編碼輸入，沒有引用來源或解釋假設的單元格註釋**
❌ 缺少 SEC 文件或資料來源的超連結（如果有）
❌ 包含太多沒有明確目的的指標
❌ 包括非可比較公司（不同商業模式）
❌ 使用過時的資料而不揭露
❌ 錯誤計算百分比平均值（應該是中位數）

### 四分位數分析的好處
四分位數不僅顯示平均/中位數，還顯示：
- **第 75 個百分點** = 「優質」公司在此進行交易
- **中位數** = 典型市場估值
- **第 25 百分位數** =「折扣」區域

這有助於回答：“與同行相比，我們的目標公司的交易價格是高還是低？”

### 針對特定行業的修改

**軟體/SaaS：**
- 新增：ARR、淨美元保留期、CAC 投資回收期
- 強調：40法、自由現金流利潤率、毛利率>70%

**醫療保健：**
- 新增：研發/收入、管道價值、監管狀態
- 強調：EBITDA 利潤率、成長率、報銷風險

**工業：**
- 新增：積壓訂單、訂單趨勢、地理組合
- 強調：ROIC、資產週轉率、週期性調整

**消費者：**
- 加：同店銷售、獲客成本、品牌價值
- 強調：營收成長、毛利率、庫存週轉率

## 第 7 部分：工作流程與實用技巧

### 逐步過程
1. **建立結構**（30 分鐘）
   - 建立所有標題
   - 設定儲存格格式（藍色表示輸入，黑色表示公式）
   - 鎖定單位和日期參考

2. **收集資料**（60-90 分鐘）
   - 從主要來源取得（S&P Kensho MCP、FactSet MCP、Daloopa MCP（如果有）；否則為 Bloomberg、SEC）
   - 輸入所有藍色的原始數字
   - 註釋部分的文檔來源

3. **建構公式**（30 分鐘）
   - 從簡單的比率（邊距）開始
   - 進展倍數（EV/收入）
   - 增加交叉檢查（邊距有意義嗎？）

4. **新增統計資料**（15 分鐘）
   - 複製所有列的公式結構
   - 驗證範圍是否正確（B7:B9，而非 B7:B10）
   - 檢查四分位數邏輯

5. **品質控制**（30 分鐘）
   - 運行健全性檢查
   - 驗證公式參考
   - 檢查#DIV/0！或#REF！錯誤
   - 與已知基準進行比較

6. **文檔**（15 分鐘）
   - 完成筆記部分
   - 新增資料來源
   - 定義方法
   - 為分析新增日期標記

### 專業提示
- **儲存範本**：建置一次，永久重複使用
- **顏色代碼離群值**：>2 個標準差的值的條件格式
- **連結到來源文件**：彭博螢幕截圖或 SEC 文件的超鏈接
- **版本控制**：另存為“Comps_v1_2024-12-15”，並註明日期
- **協作審查**：讓其他人檢查您的公式

### Excel 格式檢查表（選用 - 適應使用者偏好）
- [ ] 字體設定為使用者首選樣式（預設：Times New Roman、11pt 資料、12pt 標題）
- [ ] 根據使用者範本格式化的節標題（預設值：深藍色#17365D，白色粗體文字）
- [ ] 根據使用者範本格式化的列標題（預設值：淺藍色/灰色#D9E2F3，帶有黑色粗體文字）
- [ ] 依使用者範本格式化的統計行（預設值：淺灰色#F2F2F2）
- [ ] 無邊框（乾淨、簡約的外觀）
- [ ] **列寬設定為均勻/均勻寬度**（創造乾淨、專業的外觀）
- [ ] **行高設定為一致的高度**（資料行通常為 20-25pt）
- [ ] 使用適當的小數精度和千位分隔符號格式化的數字
- [ ] **所有指標居中對齊**，以獲得乾淨、統一的外觀

- [ ] **每個硬編碼輸入單元格都有一個註釋，其中包含：(1) 確切的資料來源，或 (2) 假設解釋**
- [ ] **在適用的情況下將超連結新增至儲存格**（SEC 檔案、資料提供者頁面、報表）

## 第 10 節：危險信號和警告標誌

### 數據品質問題
🚩 時段不一致（混合季度和年度）
🚩 缺少數據且沒有解釋
🚩 資料來源之間存在顯著差異（>10% 變異數）

### 估值危險訊號
🚩 負 EBITDA 公司以 EBITDA 倍數估值（使用營收倍數）
🚩 本益比 >100 倍，沒有高速成長的故事
🚩 對業界來說沒有意義的利潤

### 可比性問題
🚩 不同的財政年度結束（導致時間安排問題）
🚩修復單一企業和企業集團
🚩 本質上不同的商業模式被標記為“comps”

**如有疑問，請排除該公司。 ** 擁有 3 個完美的比較比 6 個有問題的比較好。

### 基本 Excel 公式
```excel
// Statistical Functions
=AVERAGE(range)          // Simple mean
=MEDIAN(range)           // Middle value
=QUARTILE(range, 1)      // 25th percentile
=QUARTILE(range, 3)      // 75th percentile
=MAX(range)              // Maximum value
=MIN(range)              // Minimum value
=STDEV.P(range)          // Standard deviation

// Financial Calculations
=B7/C7                   // Simple ratio (Margin)
=SUM(B7:B9)/3            // Average of multiple companies
=IF(B7>0, C7/B7, "N/A")  // Conditional calculation
=IFERROR(C7/D7, 0)       // Handle divide by zero

// Cross-Sheet References
='Sheet1'!B7             // Reference another sheet
=VLOOKUP(A7, Table1, 2)  // Lookup from data table
=INDEX(MATCH())          // Advanced lookup

// Formatting
=TEXT(B7, "0.0%")        // Format as percentage
=TEXT(C7, "#,##0")       // Thousands separator
```

### 常見比率公式
```excel
Gross Margin = Gross Profit / Revenue
EBITDA Margin = EBITDA / Revenue
FCF Margin = Free Cash Flow / Revenue
FCF Conversion = FCF / Operating Cash Flow
ROE = Net Income / Shareholders' Equity
ROA = Net Income / Total Assets
Asset Turnover = Revenue / Total Assets
Debt/Equity = Total Debt / Shareholders' Equity
```

## 關鍵原則總結

1. **結構驅動洞察力** - 正確的標題迫使正確的思考
2. **少即是多** - 5-10 個重要指標勝過 20 個不重要指標
3. **為您的問題選擇指標** - 估值分析≠效率分析
4. **統計資料顯示模式** - 中位數/四分位數顯示高於平均值
5. **透明度勝過複雜性** - 每個人都理解的簡單公式
6. **可比較性為王** - 排除比強加不良比較好
7. **記錄您的選擇** - 在註釋部分解釋哪些指標以及原因
