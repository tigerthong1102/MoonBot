# 數據視覺化

在生成圖表、儀表板、地圖或資料視覺化之前使用此技能。

## 工作流程

1. 確定分析任務：比較、趨勢、分佈、關係、
   排名、部分到整體、地理位置或狀態監控。
2. 選擇能夠回答該任務的最簡單的圖表形式。閱讀
   `references/choosing-a-form.md`當形態不明顯時。
3. 將發現寫入標題、副標題、軸標籤或直接註釋中。
   觀眾應該知道發生了什麼變化，什麼是高或低，或做出了什麼決定
   圖表支援。
4. 從 `references/palette.md` 中選擇顏色，或使用以下命令驗證任何自訂調色板
   下面的腳本。
5. 在最終確定設計之前檢查`references/anti-patterns.md`。

## 調色板驗證

解析相對於該技能主體上方顯示的技能基礎目錄的路徑。
不要假設為普通 shell 指令設定了 `$QWEN_SKILL_ROOT`。

運行：

```bash
node <skill-base-directory>/scripts/validate_palette.js '#1d4ed8,#b45309,#166534' --mode light
```

將 `FAIL` 視為所需的調色板變更。僅當以下情況時才將 `WARN` 視為可接受
該圖表還使用標籤、形狀、紋理、排序或其他次要的
編碼。

## 標記規則

- 對無序組使用分類調色板；使用順序或發散
  斜坡僅適用於有序值。
- 當圖表的系列數量較少時，優先選擇直接標籤而不是圖例。
- 保持網格線微妙且少於資料標記。
- 避免使用雙軸，除非兩個系列都有一個明確解釋的轉換。
- 不要只依靠顏色來進行關鍵區分。
- 保持儀表板易於掃描：對齊卡片、使用一致的數位格式、
  並為重要的狀態變化保留飽和顏色。
