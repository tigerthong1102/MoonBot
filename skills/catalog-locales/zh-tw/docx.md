# 建立和編輯 Word 文檔

使用可用的 DOCX 工具建立或編輯副本。確認部分和輸出路徑。在支援的情況下保留樣式、表格、頁首、頁尾和註釋。根據要求使用帶有追蹤更改的工具。儲存、重新開啟並檢查標題、文字和表格。當佈局很重要時檢查渲染的副本。
## 本機文件流程

在已設定 `startupbot-python` 的 Mac 上，使用其 `python-docx` 套件建立及編輯一般文件。其他電腦應使用已設定的文件工具或已安裝的相容函式庫。編輯前檢查來源文件，並在副本上工作。除非使用者要求更改，否則保留作者的結構與措辭。使用適當的標題樣式、易讀的邊界、真正的表格及一致的排版。若工具支援，為提供資訊的圖片加入無障礙描述。

重新開啟儲存的文件，檢查標題、段落及表格。若有 LibreOffice 等轉譯工具，輸出 PDF 並檢查頁面裁切、表格損壞、空白頁及圖片錯位。若文件包含註解、追蹤修訂、欄位或所選函式庫無法可靠編輯的其他元素，請使用相容工具，或說明限制並保留原件。其他上游技巧請參閱 `references/upstream.md`；其中的選用指令碼及 npm 套件須另外確認是否可用。
