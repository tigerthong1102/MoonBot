# 股票研究收益更新

根據機構標準（摩根大通、高盛、摩根士丹利格式），建立專業的**收益更新報告**，分析已涵蓋公司的季度業績。

**主要特徵：**
- **長度**：8-12 頁
- **字數**：3,000-5,000 字
- **表格**：1-3 個總表（不全面）
- **數字**：8-12 圖表
- **週轉**：1-2 天（收益後 24-48 小時內）
- **受眾**：已經熟悉公司的客戶
- **焦點**：新內容 - 失敗/失敗、更新的估計、論文影響
- **字型**：通篇使用 Times New Roman（除非使用者另有指定）

## 何時使用

當用戶請求時使用：
- “為 [公司] 2024 年第 3 季創建收益更新”
- “分析[公司]的季度業績”
- “[公司]的獲利報告”
- “[公司] 第一季/第二季/第三季/第四季更新”

**若有以下情況，請勿使用：**
- 使用者要求「啟動報告」→使用不同的技能
- 使用者請求「Flash Note」或「Quick Take」 → 不同的格式
- 公司尚未涵蓋 → 需要先啟動

## 關鍵要求

### 1. 速度和及時性
- 財報發布後 24-48 小時內發布
- 只關注新資訊
- 不要廣泛重複公司背景

### 2. 擊敗/錯過分析
- 領導公司是否超出或低於預期
- 量化差異（例如，「收入超出 1.2 億美元或 3%」）
- 解釋為什麼結果與預期不同

### 3.摘要格式
- 將表格保留為 1-3（僅摘要，不全面）
- 沒有完整的損益表/現金流量/資產負債表（只有關鍵指標）
- 假設讀者已經看到啟動報告

### 4. 引文和來源歸屬 ⭐⭐⭐ 強制

**關鍵**：正確引用具有特定來源和可點擊超連結的所有資料。

**在每個圖和表格中包含帶有可點擊連結的具體引文：**

```
Source: Q3 2024 10-Q filed November 8, 2024; Company earnings release
        [Hyperlink "10-Q" to: https://www.sec.gov/cgi-bin/viewer?accession=...]
        [Hyperlink "earnings release" to: https://investor.company.com/news/q3-2024]
```

**超連結在 WORD 中應如何顯示：**
- 文件名稱顯示為藍色、帶下劃線的可點擊鏈接
- 讀者可以Ctrl+點擊直接開源
- 非純文字 URL - 帶有顯示文字的格式化超鏈接

**所需來源清單：**

在每次收益更新中引用：
- ✅ 收益發布（帶有日期和 URL）
- ✅ 10-Q 歸檔（包含歸檔日期和 EDGAR 連結）
- ✅ 財報電話會議紀錄（附日期）
- ✅ 投資者介紹/補充資料（如果有）
- ✅ 共識估計來源（Bloomberg/FactSet/等，附日期）
- ✅ 事先指引（來自上一季的資料）

**帶有可點擊超連結的參考部分：**

在報告末尾新增「來源」部分：

```
SOURCES & REFERENCES

Earnings Materials (Q3 2024):
• Earnings Release (November 7, 2024)
  [Hyperlink entire line to: https://investor.company.com/news/q3-2024-earnings]

• Form 10-Q (Filed November 8, 2024)
  [Hyperlink to: https://www.sec.gov/cgi-bin/viewer?accession=...]

• Earnings Call Transcript (November 7, 2024)
  [Hyperlink to: https://seekingalpha.com/article/...]

• Investor Presentation (November 7, 2024)
  [Hyperlink to: https://investor.company.com/presentations/q3-2024.pdf]
```

**驗證清單：**
- [ ] 每個數字都有來源以及特定文件和日期
- [ ] 每個表格都有來源和文件參考
- [ ] 失敗/失敗分析引用了帶有日期的共識來源
- [ ] 指南變更引用目前和先前的指南來源
- [ ] 關鍵統計數據有註腳
- [ ] 來源部分列出了所有帶有 URL 的資料
- [ ] 所有 URL 都是可點擊的超連結（不是純文字）
- [ ] 所有 SEC 文件均連結至 EDGAR 檢視器

### 5. 更新的估計
- 根據結果更新遠期估計
- 清楚地顯示舊的與新的估計
- 解釋發生了什麼變化以及原因

## 高階工作流程

收益更新過程分為 5 個階段：

### 第 1 階段：資料收集（30-60 分鐘）

**🚨🚨🚨 嚴重：訓練資料已過時 🚨🚨🚨**

**開始之前 - 依序完成以下 4 個步驟：**
1. **檢查今天的日期** - 寫下當前日期
2. **搜尋最新** - 使用網路搜尋：“[公司]最新收益結果”
3. **驗證日期** - 確認收益發布是在過去 3 個月內
4. **檢查轉錄日期** - 驗證轉錄日期與發布日期相符

**常見錯誤**：使用訓練資料中過時的財報電話，而不是搜尋最新資料。

**要求：**
- ✅ 搜尋最新收益 - 不要依賴訓練數據
- ✅ 寫下今天的日期和找到的發布日期
- ✅ 驗證發布日期是在今天之後的 3 個月內
- ✅ 驗證成績單日期是否與發布日期相符
- ✅ 如果日期不符或已過時（> 3 個月），請重新搜尋

**請參閱 [references/workflow.md](references/workflow.md)** 以了解詳細的搜尋流程和驗證步驟。

### 第 2 階段：分析（2-3 小時）
- 每個關鍵指標的節拍/缺失分析
- 細分市場/地理/產品細分
- 保證金和指導分析
- 更新財務模型和估計

**詳細分析架構請參閱[references/workflow.md](references/workflow.md)**。

### 第 3 階段：圖表產生（1-2 小時）
建立 8-12 個圖表，重點關注季度趨勢和新動態：
- 季度營收進展
- 季度每股收益進展
- 季度利潤率趨勢
- 按細分市場/地區劃分的收入
- 關鍵營運指標
- 失敗/失敗總結
- 估計修訂
- 估值圖表

**請參閱 [references/workflow.md](references/workflow.md)** 以了解圖表規格。

### 第 4 階段：建立報告（2-3 小時）
建立具有特定結構的 8-12 頁 DOCX 報告。

**請參閱 [references/report-struct.md](references/report-structure.md)** 以了解完整的逐頁範本和格式要求。

**高層結構：**
- 第 1 頁：帶有評級和目標價格的收益摘要
- 第 2-3 頁：詳細結果分析
- 第 4-5 頁：關鍵指標與指南
- 第 6-7 頁：更新的投資論文
- 第 8-10 頁：估價與估算
- 第 11-12 頁：附錄（可選）

### 第 5 階段：品質檢查和交付（30 分鐘）
在交付前驗證內容、格式、準確性和及時性。

**請參閱 [references/best-practices.md](references/best-practices.md)** 以了解品質檢查表和要避免的常見錯誤。

## 輸出規格

**主要交付成果**：DOCX 報告（8-12 頁）
**檔名**：`[Company]_Q[Quarter]_[Year]_Earnings_Update.docx`
**範例**：`Nike_Q2_FY24_Earnings_Update.docx`

**內容：**
- 第 1 頁：評級摘要、目標價、要點
- 第 2-3 頁：詳細結果分析
- 第 4-5 頁：關鍵指標與指導
- 第 6-7 頁：更新的論文評估
- 第 8-10 頁：估價與估算
- 第 11-12 頁：附錄（可選）
- 8-12 嵌入圖表
- 1-3匯總表
- 帶有可點擊超連結的完整來源部分

**可選交付成果**：XLS 模型更新（收益更新可選）
