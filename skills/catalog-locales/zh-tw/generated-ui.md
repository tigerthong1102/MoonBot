# 在 StartupBot 中顯示互動式計算器或比較

當使用者想要變更輸入時，請使用 StartupBot show_html 或小工具。呈現初步結果以及簡短的解釋。將計算保留在視圖中，標記單位和輸入，拒絕無效數值，並在沒有互動式介面的情況下提供公式表。

對比較、模擬或可調整假設使用互動視圖；單一事實以文字回答，並遵循檔案或專案要求。標明範例輸入、假設和單位；計算並檢查初始結果及至少一個修改輸入的情況。使用本次工作階段實際提供的 `show_html` 或 widget schema，不使用不相容的 Qwen `generated_ui_show` API。支援時提供有用的 `fallback_text`。除非使用者明確要求並授權外部存取，計算保持本機；不要暗示滑桿會傳送訊息或執行外部操作。無法顯示或驗證視圖時，以文字提供計算和限制。
