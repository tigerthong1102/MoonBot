# 文件（v1）

> **先決條件：** 閱讀 `../gws-shared/SKILL.md` 了解身份驗證、全域標誌和安全規則。如果缺少，請執行 `gws generate-skills` 建立它​​。

```bash
gws docs <resource> <method> [flags]
```

## 輔助命令

| 指令 | 說明 |
|---------|-------------|
| `+write` | 將文字附加到文件 |

## API資源

### 文件

  - `batchUpdate` — 對文件套用一項或多項更新。每個請求在應用之前都會經過驗證。如果任何請求無效，則整個請求將失敗並且不會套用任何內容。有些請求會得到回复，為您提供一些有關如何應用它們的資訊。其他請求不需要回傳訊息；這些都傳回一個空回覆。回覆的順序與請求的順序一致。
  - `create` — 使用請求中給出的標題建立空白文件。請求中的其他欄位（包括任何提供的內容）將被忽略。傳回已建立的文檔。
  - `get` — 取得指定文件的最新版本。

## 發現命令

在呼叫任何 API 方法之前，請檢查它：

```bash
# Browse resources and methods
gws docs --help

# Inspect a method's required params, types, and defaults
gws schema docs.<resource>.<method>
```

使用 `gws schema` 輸出來建構 `--params` 和 `--json` 標誌。
