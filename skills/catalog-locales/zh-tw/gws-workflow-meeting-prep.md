# 工作流程+會議準備

> **先決條件：** 閱讀 `../gws-shared/SKILL.md` 了解身份驗證、全域標誌和安全規則。如果缺少，請執行 `gws generate-skills` 建立它​​。

準備下一次會議：議程、與會者和連結文檔

## 用途

```bash
gws workflow +meeting-prep
```

## 旗幟

| 標誌 | 必需 | 預設 | 描述 |
|------|----------|---------|-------------|
| `--calendar` | — | 主要 | 日曆 ID（預設值：主要）|
| `--format` | — | — | 輸出格式：json（預設）、table、yaml、csv |

## 範例

```bash
gws workflow +meeting-prep
gws workflow +meeting-prep --calendar Work
```

## 溫馨提示

- 只讀——從不修改資料。
- 顯示下一個即將舉行的活動以及與會者和說明。
