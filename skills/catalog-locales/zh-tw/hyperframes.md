# 使用本機 HyperFrame 建立視頻

使用現有的 HyperFrames 安裝從原始或授權媒體建置影片。就持續時間、寬高比、腳本和輸出路徑達成一致。使用本地 CLI 幫助確認特定於版本的命令。 Lint、檢查和預覽構圖並檢查過渡周圍的畫面。查看預覽後渲染本地 MP4。在 CLI 環境中設定 HYPERFRAMES_NO_TELEMETRY=1。使用已安裝並清除的字型進行輸出。
