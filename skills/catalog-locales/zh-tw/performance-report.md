# 績效報告

> 使用工作區為下面指定的資料來源配置的連接器。如果連接器不可用，請要求匯出。

產生包含關鍵指標、趨勢分析、見解和優化建議的行銷績效報告。

## 觸發

使用者運行 `/performance-report` 或要求提供行銷報告、績效分析、活動結果或指標摘要。

## 輸入

1. **報告類型** — 決定使用者需要哪種類型的報告：
   - **活動報告** — 特定活動的表現
   - **管道報告** — 特定管道（電子郵件、社交、付費、SEO 等）的績效
   - **內容表現** — 內容片段的表現如何
   - **整體行銷報告** — 跨通路總結（每週、每月、每季）
   - **自訂** — 使用者定義的範圍

2. **時段** — 報告視窗（上週、上個月、上個季度、自訂日期範圍）

3. **資料來源**：
   - 如果~~行銷分析已連接，請發現可用的帳戶和平台，然後自動提取效果數據
   - 如果~~產品分析已連線：自動擷取效能數據
   - 如果未連接：請用戶提供指標。提示：“請貼上或分享您的績效數據。我可以使用電子表格、CSV 數據、文本中描述的儀表板螢幕截圖，或僅使用關鍵數字。”

4. **比較期間**（可選）－趨勢背景的前期或同比

5. **利害關係人受眾**（可選）－誰會閱讀本報告（執行摘要風格與詳細分析師觀點）

## 報告結構

### 1. 執行摘要
- 2-3句話概述該期間的表現
- 具有趨勢方向的標題指標（與上一期相比上升/下降/持平）
- 一場關鍵勝利和一個值得關注的領域

### 2. 關鍵指標儀表板

在總表中顯示核心指標：

| 指標 | 本期 | 上一期 | 變化 | 目標 | 狀態 |
|--------|------------|--------------|--------|--------|--------|

狀態指示燈：
- 步入正軌（達到或超過目標）
- 有風險（低於目標但在可接受的範圍內）
- 偏離軌道（明顯低於目標）

#### 按報告類型劃分的指標

**活動報告：**
- 展示次數和覆蓋範圍
- 點擊率（CTR）
- 轉換率
- 每次轉換成本 (CPA)
- 廣告支出回報率 (ROAS) 或 ROI
- 總轉換/註冊/潛在客戶

**頻道報告（電子郵件）：**
- 電子郵件已發送、已送達、已退回
- 打開率
- 點擊率
- 退訂率
- 轉換率

**頻道報告（社交）：**
- 展示次數和覆蓋範圍
- 參與率（按讚、留言、分享）
- 追隨者增長
- 點擊率
- 表現最佳的帖子

**頻道報告（付費）：**
- 花費
- 展示次數和點擊次數
- 點擊率
- 每次點擊費用和每千次曝光費用
- 轉換和每次轉換費用
- 投資報酬率

**頻道報告（SEO/有機）：**
- 有機會議
- 關鍵字排名（變動）
- 已編入索引的頁面
- 獲得反向鏈接
- 表現最好的頁面

**內容表現：**
- 綜合瀏覽量和獨立訪客
- 頁面停留時間
- 跳出率
- 社群分享
- 歸因於內容的轉化
- 表現最好和最差的人

**整體行銷報告：**
- 產生的潛在客戶總數
- 行銷合格潛在客戶 (MQL)
- 管道貢獻
- 獲客成本（CAC）
- 逐個頻道匯總

### 3. 趨勢分析
- 一段時間內的表現趨勢（週環比或月環比）
- 值得注意的拐點及其產生原因
- 觀察到的季節性或週期性模式
- 與基準或目標的比較

### 4. 什麼有效
- 具體數據前3-5名獲勝
- 為什麼這些表現良好（假設）
- 如何複製或擴展

### 5. 需要改進的地方
- 表現最差 3-5 名的具體數據
- 表現不佳的假設
- 建議修復

### 6. 見解和觀察
- 僅從指標來看數據中的模式並不明顯
- 受眾行為洞察
- 引起共鳴的內容或創意主題
- 可能影響績效的外在因素（季節性、新聞、競爭措施）

### 7. 建議
對於每項建議：
- 該怎麼辦
- 為什麼（連結到數據中的特定見解）
- 預期影響（高、中、低）
- 實施力道（高、中、低）
- 優先級（立即、下一個衝刺、下個季度）

以 2x2 矩陣格式決定建議的優先順序：

| | 低努力 | 高努力 |
|---|---|---|
| **高影響** | 先做 | 計畫下一個衝刺 |
| **低影響** | 如果時間允許的話 | 降低優先權 |

### 8. 下一期重點
- 未來一段時期的三大優先事項
- 要運行的測試或實驗
- 關鍵指標的目標

## Cadence 的報告模板

### 每週行銷報告
團隊站立會議的快速瀏覽格式：
- **前 3 名的指標** 每週變化
- **本週的有效方法**（1-2 個要點和數據）
- **需要注意什麼**（1-2個要點和數據）
- **本週的優先事項**（3-5 個行動項目）

### 每月行銷報告
標準利害關係人報告：
1. 執行摘要（3-5 句）
2. 關鍵指標儀表板（包含 MoM 和目標比較的表格）
3. 逐通道性能摘要
4. 活動亮點和結果
5. 什麼有效，什麼無效（帶有假設）
6. 建議和下個月的優先事項
7. 預算支出與計劃

### 季度業務回顧 (QBR)
領導力策略審查：
1. 季度績效與目標
2. 年初至今的軌跡
3. 通路投資報酬率分析
4. 活動績效總結
5. 競爭和市場觀察
6. 下季策略建議
7. 預算請求和分配計劃
8. 關鍵實驗與學習

### 儀表板設計原則
- 以與業務目標相對應的指標（而非虛榮指標）為主導
- 顯示一段時間內的趨勢，而不僅僅是時間點快照
- 包括比較背景：前期、目標、基準
- 使用一致的顏色編碼：綠色（正常）、黃色（有風險）、紅色（偏離軌道）
- 依通路階段或業務問題將指標分組
- 將儀表板保留在一頁/螢幕上 - 詳細資訊請參閱附錄
- 更新節奏應與決策節奏相符（付費為實時，內容為每週）

## 趨勢分析與預測

### 趨勢識別
分析性能數據時，請尋找：

1. **方向趨勢**：指標在 4 個以上的週期內持續上升、下降還是持平？
2. **拐點**：績效在哪裡改變方向，然後發生了什麼事？
3. **季節性**：是否有按週、月或季度計算的可預測模式？
4. **異常**：一次性峰值或下降 - 是什麼導致了它們？它們是否可重複？
5. **領先指標**：哪些指標會先改變並預測未來的結果？

### 趨勢分析流程
1. 將指標隨時間變化繪製圖表（至少 8-12 個數據點才能反映有意義的趨勢）
2. 確定整體方向（向上、向下、平坦、循環）
3. 計算變化率（是加速還是減速？）
4. 涵蓋關鍵事件（行銷活動啟動、產品變更、市場事件）
5. 與基準或目標進行比較
6. 確定與其他指標的相關性
7. 形成關於因果關係的假設（並計劃測試來驗證）

### 簡單的預測方法
- **線性投影**：向前延伸當前趨勢線（對於穩定指標有用）
- **移動平均**：透過對最後 3-6 個週期進行平均來消除噪音
- **年比比較**：使用去年的模式作為基準，根據成長率進行調整
- **漏斗數學**：根據輸入預測輸出（例如，如果我們以 Y 轉換率產生 X 潛在客戶，我們將獲得 Z 客戶）
- **場景建模**：建立最佳情況、預期情況和最壞情況預測

### 預測注意事項
- 短期預測（1-3 個月）比長期預測更可靠
- 基於少於 12 個數據點的預測應標記為低置信度
- 外部因素（市場變化、競爭措施、經濟變化）可能會使基於趨勢的預測失效
- 始終將預測顯示為範圍，而不是確切的數字

## 歸因建模基礎知識

### 什麼是歸因？
歸因決定了哪些行銷接觸點獲得轉換。這很重要，因為買家在轉換之前通常會與多個管道互動。

### 常見歸因模型

| 型號 | 工作原理 | 最適合 | 限制 |
|-------|-------------|----------|------------|
| 最後一次接觸 | 100% 歸功於轉化前的最後一次互動 | 了解最終轉化觸發因素 | 忽略認知和培養 |
| 首次接觸 | 100% 歸功於首次互動 | 了解漏斗頂部的有效性 | 忽略培育和轉換驅動因素 |
| 線性 | 所有接觸點均等信用 | 所有管道的公平表示 | 不反映相對影響 |
| 時間衰減 | 更信任接近轉化的接觸點 | 有利於最近互動的平衡觀點 | 可能低估意識 |
| 基於位置（U 型）| 首先 40%，最後 40%，中間分配 20% | 重視發現與轉換 | 加權有些隨意 |
| 資料驅動 | 基於轉換模式的演算法信用 | 最準確的表示 | 需要大量資料 |

### 歸因實用指南
- 如果您沒有適當的模型，請從最後一次接觸歸因開始 - 這是最簡單且最可操作的
- 比較首次接觸和最後一次接觸，了解哪些管道可以提高認知度和轉換率
- 對於大多數 B2B 公司來說，使用基於位置（U 形）作為合理的中間立場
- 數據驅動的歸因需要高轉換量才能有統計意義
- 沒有一個模型是完美的－定向使用歸因，而不是絕對真理
- 多點觸摸歸因優於單點觸摸，但任何模型都比沒有好

### 歸因陷阱
- 不要基於單點觸控歸因單獨優化一個頻道
- 在最後接觸模型中，認知管道（展示、社交、公關）總是看起來很糟糕
- 在首次接觸模型中，轉換管道（搜尋、重新導向）總是看起來很糟糕
- 自我報告歸因（「您是如何聽說我們的？」）提供了有用的定性色彩，但作為定量數據並不可靠
- 跨裝置和跨渠道追蹤差距意味著歸因數據始終不完整

## 優化建議框架

### 優化流程
1. **辨識**：哪些指標與目標或基準相比表現不佳？
2. **診斷**：問題出在漏斗的哪個位置？ （展示次數、點擊次數、轉換次數、保留率）
3. **假設**：是什麼導致了表現不佳？ （受眾、資訊、創意、報價、時機、技術）
4. **優先考慮**：哪些修復將以最少的努力產生最大的影響？
5. **測試**：設計一個實驗來驗證假設
6. **衡量**：更改是否改善了指標？
7. **擴展或迭代**：廣泛推出勝利；迭代不確定或失敗的測試

### 按漏斗階段劃分的最佳化槓桿

| 漏斗階段 | 問題訊號 | 最佳化槓桿 |
|-------------|---------------|---------------------|
| 認知度 | 展示次數低，覆蓋範圍低 | 預算、定位、管道組合、廣告素材格式 |
| 興趣 | 點擊率低，參與度低 | 廣告創意、標題、內容掛鉤、受眾定位 |
| 考慮因素 | 跳出率高，頁面停留時間短 | 登陸頁內容、頁面速度、內容相關性、使用者體驗 |
| 轉換 | 轉換率低 | 報價、CTA、表單長度、信任訊號、頁面佈局 |
| 留任率 | 高流失率、低重複參與度 | 入職、電子郵件培養、產品體驗、支援 |

### 測試最佳實踐
- 一次測試一個變數以獲得乾淨的結果
- 在啟動測試之前定義成功指標
- 在開始之前計算所需的樣本量（不要提前結束測試）
- 運行至少一個完整業務週期的測試（B2B 通常為一周）
- 記錄所有測試和結果，無論結果如何
- 在整個團隊中分享經驗教訓——失敗的測試是有價值的訊息
- 確認現狀的測試並不意味著失敗——它會增強你對當前方法的信心

### 持續優化節奏
- **每日**：監控付費廣告系列的預算節奏、異常情況和被拒絕的廣告
- **每週**：檢視通路績效，暫停錶現不佳者，擴大規模獲勝者
- **每兩週**：刷新廣告創意並測試新變體
- **每月**：全面績效評估，識別新的優化機會，更新預測
- **季度**：通路組合、預算分配和定位策略的策略審查

## 輸出格式

- 使用表格進行資料呈現
- 大膽的關鍵數字和趨勢
- 保持執行摘要簡潔（適合轉發給領導）
- 如果使用者提供了大量指標，請包含詳細資料的「詳細附錄」部分

## 報告後

問：「你希望我：
- 建立這些結果的幻燈片摘要？
- 起草一封包含關鍵要點的利害關係人電子郵件？
- 更深入地研究任何特定指標或管道？
- 設定一個可以在下一個週期重複使用的報告範本？ 」
