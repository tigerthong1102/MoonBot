# 建立和編輯 PowerPoint 投影片

規劃每張投影片的要點。使用可用的 PPTX 工具，例如已設定的 PptxGenJS 安裝。使用原創或授權媒體和可編輯圖表。保留源甲板。儲存後，重新開啟投影片並檢查投影片文字、計數和對齊方式。當渲染器可用時，請使用聯絡表來識別重疊和剪裁。
## 本機簡報流程

在已設定 `startupbot-python` 的 Mac 上，使用其 `python-pptx` 套件建立及編輯一般投影片。其他電腦應使用已設定的簡報工具或已安裝的相容函式庫。依照需求或來源檔案確定受眾、目的及投影片尺寸。讓每頁重點明確，使用易讀的文字與適當對比；在可行時優先使用可編輯的文字、圖形、表格和圖表。使用使用者提供或有權使用的素材。

另存新檔後重新開啟，檢查投影片順序、文字與關鍵資料。若有 LibreOffice 等轉譯工具，將簡報輸出為 PDF，逐頁檢查文字裁切、重疊和遺失素材。複雜動畫、轉場、註解與範本可能需要其他工具；保留原件並說明尚未驗證的變更。其他設計與製作細節請參閱 `references/upstream.md`；其中的選用指令碼和 npm 套件須另外確認是否可用。
