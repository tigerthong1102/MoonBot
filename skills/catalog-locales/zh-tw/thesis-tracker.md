# 論文追蹤器

## 工作流程

### 第 1 步：定義或載入論文

如果創建新論文：
- **公司**：名稱和股票代碼
- **位置**：多頭或空頭
- **論文陳述**：1-2 句話核心論文（例如，「長期 ACME — 隨著組合轉向軟體，定價能力 + 營運槓桿的利潤擴張」）
- **關鍵支柱**：3-5 個支持論點
- **主要風險**：3-5 個可能導致論文無效的風險
- **催化劑**：可能證明/反駁該論點的即將發生的事件（收益、產品發布、監管決策）
- **目標價格/估值**：如果論文得以實現，它的價值是多少
- **停損觸發**：什麼會讓你退出

如果更新現有論文，請向使用者詢問新的數據點或發展。

### 步驟2：更新日誌

對於每個新數據點或發展：

- **日期**：發生這種情況的時間
- **數據點**：發生了什麼變化（獲利成長、管理層離職、競爭對手變動等）
- **論文影響**：這會加強、削弱或抵銷某個特定支柱？
- **動作**：無變化/增加位置/修剪/退出
- **更新信念**：高/中/低

### 第三步：論文記分卡

維護運作記分卡：

| 支柱 | 原始預期 | 目前狀態 | 趨勢 |
|--------|---------------------|----------------|-------|
| 營收成長 >20% | 步入正軌 | 第三季成長 22% | 穩定 |
| 利潤率擴張 | 落後 | 利潤率較去年同期持平 | 關於 |
| 新品發表 | 待定 | 延後到第二季 | 觀看 |

### 第 4 步：催化劑日曆

追蹤即將到來的催化劑：

| 日期 | 事件 | 預期影響 | 註 |
|------|-------|-----------------|-------|
| | | | |

### 第五步：輸出

論文摘要適合：
- 早會討論
- 投資組合審查
- 風險委員會介紹

格式：簡潔的 Markdown 或包含記分卡、最近更新和當前信念等級的 Word 文件。

## 重要提示

- 論文應該是可證偽的——如果沒有什麼可以反駁它，那麼它就不是論文
- 像確認證據一樣嚴格追蹤否定證據
- 至少每季回顧一次論文，即使沒有發生任何戲劇性的事情
- 如果用戶管理多個職位，請提供完整的作品集論文審查
- 以結構化格式儲存論文數據，以便跨會話引用
