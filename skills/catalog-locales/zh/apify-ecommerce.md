# 使用经批准的 Apify 来源研究产品列表和评论

使用配置的只读连接和公共或授权源。仅收集请求的字段。记录列表 URL、货币、显示价格和日期。单独的运输、增值税和促销。总结没有客户标识符的评论模式。
## 研究流程

确定电商平台、搜索词或公开商品 URL、所需字段、国家和结果数量限制。通过已配置的 Apify 连接查找 Actor，选择前检查输入结构、价格和文档说明的覆盖范围。公开发现工具无需账户访问即可列出 Actor 和文档。运行 Actor 需要经授权的 Apify 账户，可能消耗额度或产生费用。付费运行前确认预算，并在服务支持时设置最高费用。

先从小样本开始。尽可能获取商品名称、来源 URL、观察到的价格、币种、库存状态和时间。等待运行完成并检查结果数据集；运行成功仍可能没有商品或缺少字段。区分缺失值与零，保留平台和卖家背景，并说明观察时间及限制。比较时，仅在有汇率及其日期时换算币种；来源允许时分别列出运费、促销和税费。

官方远程 Apify MCP 服务器支持公开发现以及通过 OAuth 访问已认证账户。使用现有配置的连接；如没有，请说明需要何种连接。切勿将 API 令牌放入聊天消息或 URL。用户应通过应用的连接流程授权。
