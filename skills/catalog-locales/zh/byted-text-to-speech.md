# 使用授权的字节跳动语音连接器生成旁白

使用现有的字节跳动 TTS 连接。确认文本、语音选择和音频格式。合成音频，将其保存在任务工作区中，并检查持续时间和声音质量。仅使用用户有权使用的声音。

如果尚未连接字节跳动，请说明该服务需要单独开通且可能收费；不要声称聊天订阅包含该服务。如果用户同意使用其他语音提供方，并且使用的是 Mac，可提供系统语音合成作为本地替代方案。使用 `say -v '?'` 列出可用声音，选择符合所需语言的已安装声音，再用 `say -v VOICE -f INPUT_TEXT_FILE -o OUTPUT.aiff` 写入新的 `.aiff` 文件。使用任务专用文本文件或标准输入，避免私人文本进入 shell 命令历史。检查输出文件存在、时长大于零且声音清晰。明确说明这是 macOS 声音，不是字节跳动声音；质量和可用声音因机器而异。对于其他平台或声音不可用的情况，应说明缺少的条件，不要声称合成成功。
