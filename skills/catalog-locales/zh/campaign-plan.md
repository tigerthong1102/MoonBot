# 活动计划

> 使用工作区为下面指定的数据源配置的连接器。如果连接器不可用，请请求导出。

生成全面的营销活动简介，其中包含目标、受众、消息传递、渠道策略、内容日历和成功指标。

## 触发

用户运行 `/campaign-plan` 或要求规划、设计或开展营销活动。

## 输入

从用户那里收集以下信息。如果未提供，请在继续之前询问：

1. **活动目标** — 主要目标（例如，推动注册、提高知名度、推出产品、产生潜在客户、重新吸引流失的用户）

2. **目标受众** - 活动的目标人群（人口统计、角色、行业、痛点、购买阶段）

3. **时间表** — 活动持续时间和任何固定日期（启动日期、活动日期、季节性截止日期）

4. **预算范围** — 大致预算或预算层级（可选；如果未提供，则生成与渠道无关的计划并注明预算分配的重要性）

5. **附加上下文**（可选）：
   - 正在推广的产品或服务
   - 关键差异点或价值主张
   - 之前的活动表现或经验教训
   - 品牌准则或限制
   - 地理重点

## 活动简介结构

生成包含以下部分的活动简介：

### 1. 活动概述
- 活动名称建议
- 一句话活动总结
- 主要目标具有具体的、可衡量的目标
- 次要目标（如果适用）

### 2. 目标受众
- 主要受众群体及说明
- 次要受众群体（如果适用）
- 受众痛点和动机
- 他们花时间的地方（渠道、社区、出版物）
- 购买阶段调整（意识、考虑、决策）

### 3. 关键信息
- 核心活动信息（一句话）
- 针对受众痛点量身定制的 3-4 条支持信息
- 不同频道的消息变化（如果需要不同的音调）
- 支持每条消息的证据点或证据

### 4、渠道策略
根据受众和目标推荐频道。对于每个频道，包括：
- 为什么这个频道适合受众和目标
- 内容格式建议
- 估计的努力水平（低、中、高）
- 预算分配建议（如果提供预算）

考虑渠道：
- 拥有：博客、电子邮件、网站、社交媒体资料
- 赢得：公关、有影响力的合作伙伴关系、客座帖子、社区参与
- 付费：搜索广告、社交广告、展示广告、赞助内容、活动

### 5. 内容日历
创建每周（或短期活动中的每日）内容日历：
- 每周制作什么内容
- 每件作品针对哪个频道
- 关键里程碑和截止日期
- 各个部分之间的依赖关系（例如，“着陆页必须在付费广告发布之前上线”）

格式为表格：

| 周 | 内容片段 | 频道 | 所有者/注释 | 状态 |
|------|--------------|---------|-------------|--------|

### 6. 所需内容
列出活动所需的所有内容资产：
- 资产名称和类型（博客文章、电子邮件、社交帖子、广告创意、登陆页面等）
- 简要描述应包含的内容
- 优先级（必备与最好有）
- 建议的创建时间表

### 7. 成功指标
定义与活动目标一致的 KPI：
- 主要 KPI 和目标数
- 次要 KPI (3-5)
- 如何跟踪每个指标
- 报告节奏建议

如果连接了~~产品分析，请参考任何可用的历史性能基准来告知目标。

### 8. 预算分配（如果提供预算）
- 按渠道或活动细分
- 生产成本与分销成本
- 应急建议（通常为 10-15%）

### 9. 风险和缓解措施
- 2-3个潜在风险（时间线、受众不匹配、渠道表现不佳）
- 每个的缓解策略

### 10. 后续步骤
- 启动活动的立即行动项目
- 需要利益相关者的批准
- 关键决策点

## 规划参考

### 活动框架：目标、受众、信息、渠道、措施

每个活动都应该建立在这个由五部分组成的框架之上：

#### 目的
在计划其他事情之前先定义成功是什么样的。

- **意识**：提高品牌或产品知名度（通过覆盖范围、印象数、声音份额来衡量）
- **考虑因素**：推动参与度和教育（通过内容参与度、电子邮件注册、网络研讨会出席率来衡量）
- **转化**：产生潜在客户或销售（通过注册、演示、购买、渠道来衡量）
- **保留**：重新吸引现有客户（通过减少流失、追加销售、净推荐值来衡量）
- **宣传**：将客户转变为推广者（通过推荐、评论、UGC 来衡量）

好的目标是明智的：具体的、可衡量的、可实现的、相关的、有时限的。

示例：“在活动启动后 6 周内，从北美中端市场 SaaS 公司产生 200 个符合营销资格的潜在客户。”

#### 观众
明确定义您想要联系的对象，以指导消息传递和渠道决策。

- **人口统计**：角色/头衔、资历、公司规模、行业
- **心理统计**：动机、痛点、目标、反对意见
- **行为**：他们在哪里消费内容、如何购买、之前接触过什么
- **购买阶段**：他们是否没有意识到问题、正在研究解决方案或准备购买？

为活动规划创建一个简短的受众档案（不是完整的角色）：
> “[公司类型]的[角色]正在与[痛点]作斗争并寻找[期望的结果]。他们通常通过[渠道]发现解决方案，并且最关心[优先事项]。”

#### 留言
精心设计能引起观众共鸣的核心信息和支持点。

- **核心信息**：用一句话来表达您希望观众思考、感受或做的事情
- **支持信息**：提供证据、解决异议或详细说明好处的 3-4 点
- **证明点**：每条支持信息的数据、案例研究、推荐或第三方验证
- **差异化**：是什么让您的产品与其他产品不同（包括什么都不做）

消息层次结构：
1. 我为什么要关心？ （解决痛点或机会）
2. 解决办法是什么？ （定位您的产品）
3. 为什么是你？ （与替代品不同）
4. 我该怎么办？ （号召性用语）

#### 频道
根据您的受众所在位置而不是您最舒服的位置来选择频道。请参阅下面的渠道选择指南。

#### 测量
定义您如何知道活动是否有效。请参阅下面按活动类型划分的成功指标。

### 渠道选择指南

#### 自有频道

| 渠道 | 最适合 | 典型指标 | 努力 |
|---------|----------|----------------|--------|
| 博客/网站 | SEO、思想领导力、教育 | 流量、页面停留时间、转化 | 中等 |
| 电子邮件 | 培养、留存、公告 | 打开率、点击率、转化率 | 低-中 |
| 社交（有机）| 意识、社区、品牌建设 | 参与度、影响力、追随者增长 | 中等 |
| 网络研讨会 | 教育、潜在客户发掘、产品演示 | 注册、出席、渠道 | 高 |
| 播客 | 思想领导力、品牌知名度 | 下载量、订阅者增长 | 高 |

#### 赢得频道

| 渠道 | 最适合 | 典型指标 | 努力 |
|---------|----------|----------------|--------|
| 公关/媒体 | 认知度、可信度、发布 | 覆盖率、声音份额、推荐流量 | 高 |
| 来宾内容 | 受众扩展、SEO、可信度 | 推荐流量、反向链接 | 中 |
| 影响者/合作伙伴 | 受众扩展、信任 | 覆盖面、参与度、推荐转化 | 中高 |
| 社区 | 意识、信任、反馈 | 提及、参与、推荐流量 | 媒介 |
| 评论/评级 | 可信度、SEO、考虑度 | 评论量、评级、转化提升 | 低-中 |

#### 付费频道

| 渠道 | 最适合 | 典型指标 | 努力 |
|---------|----------|----------------|--------|
| 搜索广告 (SEM) | 高意图捕获潜在客户 | CPC、CTR、转化率、CPA | 中等 |
| 社交广告 | 认知度、重定向、潜在客户发掘 | CPM、CPC、CTR、CPA、ROAS | 中等 |
| 展示广告/程序化 | 认知度、重定向 | 展示次数、每千次展示费用、浏览型转化 | 中低 |
| 赞助内容 | 思想领导力、潜在客户开发 | 参与度、潜在客户、每个潜在客户的成本 | 中等 |
| 活动/赞助 | 关系建设、品牌 | 潜在客户、会议、渠道影响 | 高 |

#### 渠道选择标准
选择渠道时，请考虑：
- 您的目标受众将时间花在哪里？
- 您的目标购买阶段是什么？ （认知渠道与转化渠道）
- 您的预算是多少？ （付费频道需要花费；拥有/赚取需要时间）
- 您已经拥有或可以制作哪些内容资产？
- 过去什么有效？ （如果有历史数据，请参考）

### 内容日历创建

#### 日历规划流程
1. **从里程碑开始**：活动启动、活动日期、产品发布、季节性时刻
2. **逆向工作**：需要直播什么以及何时直播？生产提前期是多少？
3. **将内容映射到漏斗阶段**：确保覆盖认知、考虑和转化
4. **按主题批量**：将相关内容分为每周或每两周主题
5. **平衡通道**：不要在一个通道上过度索引；确保受众跨接触点看到营销活动
6. **建立灵活性**：为反应性或投机性内容留出 20% 的日历时段

#### 内容节奏指南
- **博客**：每周 1-4 个帖子，具体取决于团队规模和目标
- **电子邮件通讯**：对于大多数受众来说每周或每两周一次
- **社交媒体**：每个平台每周 3-7 个帖子（因平台而异）
- **付费广告活动**：在广告活动期间持续进行，每 2-4 周更新一次创意
- **网络研讨会**：每月或每季度一次，具体取决于资源

#### 生产时间表基准
- 博客文章：3-5 个工作日（研究、起草、审查、发布）
- 电子邮件活动：2-3 个工作日（复制、设计、测试、发送）
- 社交媒体帖子：1-2 个工作日（草稿、设计、时间表）
- 登陆页面：5-7 个工作日（文案、设计、开发、质量检查）
- 视频内容：2-4周（剧本、制作、剪辑）
- 电子书/白皮书：2-4周（大纲、草稿、设计、审查）

### 预算分配方法

#### 收入百分比法
- 行业基准：营销收入占收入的 5-15%，B2B 通常为 5-10%，B2C 通常为 10-15%
- 初创公司和成长期公司通常将 15-25% 的收入投入营销
- 在营销预算内，跨品牌（长期）和绩效（短期）进行分配

#### 渠道分配框架
通用的起始框架（根据目标和历史数据进行调整）：

| 类别 | 预算百分比 | 示例 |
|----------|---------------------|----------|
| 付费获取 | 30-40% | 搜索广告、社交广告、展示广告 |
| 内容制作 | 20-30% | 博客、视频、设计、电子书 |
| 活动和赞助 | 10-20% | 会议、网络研讨会、聚会 |
| 工具和技术 | 10-15% | 分析、自动化、CRM |
| 测试和实验 | 5-10% | 新渠道、A/B 测试、试点 |

#### 预算优化原则
- 从您最有信心的渠道开始，并在那里分配 60-70% 的付费预算
- 预留 15-20% 用于测试新渠道或策略
- 根据绩效数据每月调整预算（不要设置后忘记）
- 考虑制作成本，而不仅仅是媒体支出
- 包括 10-15% 的意外机会或超支应急费用

### 按活动类型划分的成功指标

#### 宣传活动
| 公制 | 它测量什么 |
|--------|-----------------|
| 覆盖面/展示次数 | 有多少人观看了该活动 |
| 品牌提及量 | 品牌对话量增加 |
| 声音份额 | 您与竞争对手的提及次数 |
| 直接流量 | 人们主动访问您的网站 |
| 社交关注者增长 | 受众建设 |

#### 潜在客户开发活动
| 公制 | 它测量什么 |
|--------|-----------------|
| 潜在客户总数 | 新联系人数量 |
| 营销合格潜在客户 (MQL) | 满足质量阈值的潜在客户 |
| 每潜在客户成本 (CPL) | 支出效率 |
| 潜在客户到 MQL 的转化率 | 生成的潜在客户质量 |
| 管道影响 | 创造收入机会 |

#### 产品发布活动
| 公制 | 它测量什么 |
|--------|-----------------|
| 注册或试用 | 采用新产品 |
| 激活率 | 完成关键第一个操作的用户 |
| 媒体报道 | 获得媒体点击量 |
| 社交热议 | 提及、分享、参与度飙升 |
| 功能采用 | 特定已推出功能的使用 |

#### 保留/参与活动
| 公制 | 它测量什么 |
|--------|-----------------|
| 客户流失率变化 | 客户保留率提高 |
| 参与率 | 与活动内容的互动 |
| NPS 或 CSAT 更改 | 满意度提升 |
| 追加销售/交叉销售收入 | 扩张收入 |
| 功能采用 | 升级功能的使用 |

#### 活动/网络研讨会活动
| 公制 | 它测量什么 |
|--------|-----------------|
| 注册 | 产生兴趣 |
| 出席率 | 注册转化 |
| 活动期间的参与度 | 问题、投票、聊天活动 |
| 活动后转化 | 来自与会者的潜在客户或渠道 |
| 内容再利用覆盖范围 | 录音的下游受众 |

## 输出

呈现完整的活动简介，标题和格式清晰。简短介绍后，问：

“你想让我：
- 深入研究任何部分？
- 从日历中起草特定的内容片段？
- 创建竞争分析来传达信息？
- 根据不同的预算或时间表调整计划？”
