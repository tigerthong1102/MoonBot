# 可比公司分析

## ⚠️ 关键：数据源优先级（请先阅读）

**始终遵循此数据源层次结构：**

1. **首先：检查 MCP 数据源** - 如果 S&P Kensho MCP、FactSet MCP 或 Daloopa MCP 可用，请将它们专门用于金融和交易信息

**为什么这很重要：** MCP 来源提供经过验证的机构级数据以及正确的引用。网络搜索结果对于财务分析来说可能已经过时、不准确或不可靠。

## ⚠️ 关键：公式优于硬编码 + 逐步验证

**环境 — Office JS 与 Python：**
- **如果在 Excel 内部运行（Office 插件/Office JS）：** 直接使用 Office JS (`Excel.run(async (context) => {...})`)。通过`range.formulas = [["=E7/C7"]]`而不是`range.values`编写公式。无需单独的重新计算步骤 — Excel 会自行处理。使用 `range.format.*` 作为颜色/字体。
- **如果生成独立的 .xlsx 文件：** 使用 Python/openpyxl。写入`cell.value = "=E7/C7"`（公式字符串）。
- 无论哪种方式，原则都是相同的——只需翻译 API 调用即可。
- **Office JS 合并单元格陷阱：** 不要调用 `.merge()`，然后在合并范围上设置 `.values`（抛出 `InvalidArgument` - 范围仍报告其合并前尺寸）。而是将值单独写入左上角的单元格，然后合并+格式化整个范围：
  ```js
  ws.getRange("A1").values = [["TECHNOLOGY — COMPARABLE COMPANY ANALYSIS"]];
  const hdr = ws.getRange("A1:H1");
  hdr.merge();
  hdr.format.fill.color = "#1F4E79";
  hdr.format.font.color = "#FFFFFF";
  hdr.format.font.bold = true;
  ```

**公式，而不是硬编码：**
- 每个派生值（保证金、倍数、统计量）必须是引用输入单元格的 Excel 公式 — 绝不能是粘贴到的预先计算的数字
- 使用Python/openpyxl构建工作表时：写`cell.value = "=E7/C7"`（公式字符串），而不是`cell.value = 0.687`（计算结果）
- 唯一的硬编码值应该是原始输入数据（收入、EBITDA、股价等）——并且每一个数据都会有一个带有其来源的单元格注释
- 原因：当输入发生变化时，模型必须自动更新。硬编码边距是一个等待发生的无声错误。

**与用户逐步验证：**
- 设置结构后→在填充数据之前向用户显示标题布局
- 输入原始输入后 → 向用户显示输入块并在构建公式之前确认来源/周期
- 建立运营指标公式后→显示计算出的利润并在进行评估之前与用户进行健全性检查
- 建立估值倍数后 → 在添加统计数据之前显示倍数并确认它们看起来合理
- 不要从头到尾构建整个工作表，然后将其呈现 - 通过确认每个部分来尽早发现错误

## 第 1 部分：文档结构和设置

### 标头块（第 1-3 行）
```
Row 1: [ANALYSIS TITLE] - COMPARABLE COMPANY ANALYSIS
Row 2: [List of Companies with Tickers] • [Company 1 (TICK1)] • [Company 2 (TICK2)] • [Company 3 (TICK3)]
Row 3: As of [Period] | All figures in [USD Millions/Billions] except per-share amounts and ratios
```

**为什么这很重要：**立即建立上下文。任何打开此文件的人都知道他们正在查看的内容、文件的创建时间以及如何解释其中的数字。

### 视觉约定标准（可选 - 用户首选项和上传的模板始终覆盖）

**重要提示：这些只是建议的默认值。始终优先考虑：**
1. 用户的显式格式偏好
2. 根据任何上传的模板文件进行格式化
3. 公司/团队风格指南
4. 这些默认值（仅当未提供其他指导时）

**建议的字体和版式：**
- **字体系列**：Times New Roman（专业、可读、行业标准）
- **字体大小**：数据单元格为 11 磅，标题为 12 磅
- **粗体文本**：节标题、公司名称、统计标签

**默认颜色和阴影 - 专业蓝色/灰色调色板（越小越好）：**
- **保持克制**——只有蓝色和灰色。不要引入绿色、橙色、红色或多种强调色。干净的比较表总共使用 3-4 种颜色。
- **部分标题**（例如，“运营统计数据和财务指标”）：
  - 深蓝色背景（`#1F4E79` 或 `#17365D` 海军蓝）
  - 白色粗体文字
  - 所有列的全行阴影
- **列标题**（例如“公司”、“收入”、“利润”）：
  - 浅蓝色背景（`#D9E1F2`或类似的淡蓝色）
  - 黑色粗体文字
  - 居中对齐
- **数据行**：
  - 公司数据的白色背景
  - 公式的黑色文本；蓝色文本表示硬编码输入
- **统计行**（最大值、第 75 个百分位等）：
  - 浅灰色背景（`#F2F2F2`）
  - 黑色文本，左对齐标签
- **这就是整个调色板**：深蓝色+浅蓝色+浅灰色+白色。除非用户的模板另有说明，否则没有其他内容。

**建议的格式约定：**
- **小数精度**：
  - 百分比： 1 位小数 (12.3%)
  - 倍数：1 位小数 (13.5x)
  - 美元金额：无小数，千位分隔符 (69,632)
  - 以百分比显示的利润：小数点后 1 位 (68.7%)
- **边框**：无边框（干净、最小的外观）
- **对齐**：所有指标均居中对齐，以实现干净、统一的外观
- **单元格尺寸**：所有列宽应一致/均匀，所有行高应一致（创建干净、专业的网格）

**注意：** 如果用户提供模板文件或指定不同的格式，请改用它。

## 第 2 节：运营统计和财务指标

### 核心专栏（从这些开始）
1. **公司** - 格式一致的名称
2. **收入** - 规模指标（可以是 LTM、季度或年度，具体取决于具体情况）
3. **收入增长** - 同比百分比变化
4. **毛利润** - 收入减去销售成本
5. **毛利率** - 毛利率/收入（基本盈利能力）
6. **EBITDA** - 息税折旧摊销前利润
7. **EBITDA 利润率** - EBITDA/收入（运营效率）

### 可选添加（根据行业/用途选择）
- **季度与 LTM** - 如果季节性很重要，则包括两者
- **自由现金流** - 适用于资本密集型或 SaaS 业务
- **FCF 利润** - FCF/收入（现金生成效率）
- **净利润** - 对于成熟、盈利的公司
- **营业收入** - 适用于 D&A 不同的企业
- **资本支出指标** - 适用于重资产行业
- **40 规则** - 专门针对 SaaS（增长 % + 利润 %）
- **FCF 转换** - 用于收益分析质量（高级）

### 公式示例（以第 7 行为例）
```excel
// Core ratios - these are always calculated
Gross Margin (F7): =E7/C7
EBITDA Margin (H7): =G7/C7

// Optional ratios - include if relevant
FCF Margin: =[FCF]/[Revenue]
Net Margin: =[Net Income]/[Revenue]
Rule of 40: =[Growth %]+[FCF Margin %]
```

**黄金法则：** 每个比率都应该是[某物]/[收入]或[某物]/[此表中的某物]。保持简单。

### 统计块（公司数据之后）

**关键：为所有可比指标（比率、利润、增长率、倍数）添加统计公式。**

```
[Leave one blank row for visual separation]
- Maximum: =MAX(B7:B9)
- 75th Percentile: =QUARTILE(B7:B9,3)
- Median: =MEDIAN(B7:B9)
- 25th Percentile: =QUARTILE(B7:B9,1)
- Minimum: =MIN(B7:B9)
```

**需要统计信息的列（可比较指标）：**
- 收入增长率 %、毛利率 %、EBITDA 利润率 %、每股收益
- EV/收入、EV/EBITDA、市盈率、股息率、贝塔值

**不需要统计信息的列（大小指标）：**
- 收入、EBITDA、净利润（绝对规模因公司规模而异）
- 市值、企业价值（不同规模的公司之间不具有可比性）

**注：** 在公司数据和统计行之间添加一个空白行，以便视觉上分隔。不要添加“部门统计数据”或“估值统计数据”标题行。

**为什么四分位数很重要：** 它们显示分布，而不仅仅是平均值。 75% 的倍数告诉您“优质”公司的交易价格。

## 第 3 节：估值倍数和投资指标

### 核心估值列（从这些开始）
1. **公司** - 与运营部门相同的订单
2. **市值** - 当前市场估值
3. **企业价值** - 市值±净债务/现金
4. **EV/收入** - 每美元销售额的市场支付多少
5. **EV/EBITDA** - 每美元收益市场支付多少
6. **市盈率** - 相对于净利润的价格

### 可选的评估指标（根据上下文选择）
- **FCF 收益率** - FCF/市值（用于以现金为重点的分析）
- **PEG 比率** - 市盈率/增长率（针对成长型公司）
- **价格/账面** - 市场价值与账面价值（对于重资产企业）
- **ROE/ROA** - 回报指标（用于盈利能力比较）
- **收入/EBITDA CAGR** - 历史增长率（用于趋势分析）
- **资产周转率** - 收入/资产（用于运营效率）
- **债务/股权** - 杠杆（用于资本结构分析）

**关键原则：** 包括对您的行业重要的 3-5 个核心倍数。不要仅仅因为可以就包含所有可能的指标。

### 公式示例
```excel
// Core multiples - always include these
EV/Revenue: =[Enterprise Value]/[LTM Revenue]
EV/EBITDA: =[Enterprise Value]/[LTM EBITDA]
P/E Ratio: =[Market Cap]/[Net Income]

// Optional multiples - include if data available
FCF Yield: =[LTM FCF]/[Market Cap]
PEG Ratio: =[P/E]/[Growth Rate %]
```

### 交叉引用规则
**关键：** 估值倍数必须参考运营指标部分。切勿两次输入相同的原始数据。如果收入在 C7 中，则 EV/收入公式应参考 C7。

### 统计块
与操作部分的结构相同：每个指标的最大值、第 75 个、中值、第 25 个、最小值。添加一个空白行，以便在公司数据和统计数据之间进行视觉分隔。不要添加“评估统计”标题行。

## 第 4 部分：注释和方法文档

### 所需组件

**数据来源和质量：**
- 数据从哪里来？ （S&P Kensho MCP、FactSet MCP、Daloopa MCP、彭博社、SEC 备案）
- 涵盖什么时期？ （2024 年第四季度，经审计的数据）
- 是如何验证的？ （与 10-K/10-Q 交叉检查）
- 注意：如果有的话，优先考虑 MCP 数据源（S&P Kensho、FactSet、Daloopa），以获得更好的准确性和可追溯性

**关键定义：**
- EBITDA计算方法（毛利润+D&A，或营业收入+D&A）
- 自由现金流公式（运营 CF - 资本支出）
- 特殊指标解释（40 规则，FCF 转换）
- 时间段定义（LTM、CAGR 计算周期）

**估值方法：**
- 企业价值是如何计算的？ （市值+净债务）
- 使用了多少增长率？ （历史复合年增长率，前瞻性估计）
- 有什么调整吗？ （排除一次性项目，标准化利润）

**分析框架：**
- 投资主题是什么？ （云/SaaS 效率）
- 什么指标最重要？ （现金产生、资本效率）
- 读者应该如何解读这些统计数据？ （四分位数提供上下文）

## 第 5 节：选择正确的指标（决策框架）

### 从“我要回答什么问题？”开始

**“哪家公司被低估？”**
→ 关注：EV/收入、EV/EBITDA、市盈率、市值
→ 跳过：运营细节、增长指标

**“哪家公司效率最高？”**
→ 重点关注：毛利率、EBITDA 利润率、自由现金流利润率、资产周转率
→ 跳过：规模指标、绝对美元金额

**“哪家公司增长最快？”**
→ 关注：收入增长率、EBITDA 复合年增长率、用户/客户增长
→ 跳过：保证金指标、杠杆率

**“哪个是最好的现金生成器？”**
→ 关注：FCF、FCF 保证金、FCF 转换、资本支出强度
→ 跳过：EBITDA、市盈率

### 行业特定的指标选择

**软件/SaaS：**
必须具备：收入增长、毛利率、40 法则
可选：ARR、净美元保留、CAC 回报
跳过：资产周转率、库存指标

**制造业/工业：**
必须具备： EBITDA 利润率、资产周转率、资本支出/收入
可选：ROA、库存周转率、积压订单
跳过：40 条规则，SaaS 指标

**金融服务：**
必须具备：ROE、ROA、效率比、P/E
可选：净息差、贷款损失准备金
跳过：毛利率、EBITDA（对银行没有意义）

**零售/电子商务：**
必须具备：收入增长、毛利率、库存周转率
可选：同店销售、获客成本
跳过：大量研发或资本支出指标

### “5-10 规则”

**5 个运营指标** - 收入、增长、2-3 个利润/效率指标
**5 个估值指标** - 市值、EV、3 倍
**= 总共 10 栏** - 足以讲述故事，但不要太多以至于失去线索

如果您的指标超过 15 个，则可能会包含噪音。无情地编辑。

## 第 6 节：最佳实践和质量检查

### 开始之前
1. **定义同行群体** - 公司必须具有真正的可比性（相似的商业模式、规模、地理位置）
2. **选择正确的时期** - LTM 平滑季节性；季度显示趋势
3. **预先标准化单位** - 数百万与数十亿的决定影响一切
4. **地图数据源** - 知道每个数字来自哪里

### 当你构建时
1. **先输入所有原始数据** - 在编写公式之前完成蓝色文本
2. **将单元格注释添加到所有硬编码输入** - 右键单击单元格 → 插入注释 → 文档来源或假设

   **对于来源数据，请准确注明其来源：**
   - 示例：“彭博终端 - MSFT Equity DES，于 2024 年 10 月 2 日访问”
   - 示例：“2024 年第 4 季度 10-K 归档，第 42 页，行项目“总收入””
   - 示例：“截至 2024 年 10 月 2 日的 FactSet 共识估计”
   - **尽可能包含超链接**：右键单击单元格 → 链接 → 将 URL 粘贴到 SEC 归档、数据源或报告

   **对于假设，请解释推理：**
   - 示例：“根据同行中位数假设 EBITDA 利润率为 15%，公司未披露”
   - 示例：“估计企业价值为市值 + 5000 万美元净债务（来自第三季度的资产负债表，第四季度尚未提供）”
   - 示例：“基于 3.45 美元的街头共识 EPS 的远期市盈率（12 位分析师的平均预测）”

   **为什么这很重要**：实现审计跟踪、数据验证、假设透明度和未来更新
3. **逐行构建公式** - 在继续之前测试每个计算
4. **对标题使用绝对引用** - $C$6 锁定标题行
5. **格式一致** - 百分比为百分比，而不是小数
6. **添加条件格式** - 自动突出显示异常值

### 健全性检查
- **利润率测试**：毛利率 > EBITDA 利润率 > 净利润率（根据定义始终为真）
- **多重合理性**：
  - EV/收入：通常为 0.5-20 倍（因行业而异）
  - EV/EBITDA：通常为 8-25 倍（各行业相当一致）
  - 市盈率：通常为 10-50 倍（取决于增长率）
- **增长与倍数相关性**：较高的增长通常意味着较高的倍数
- **规模效率权衡**：较大的公司通常有更好的利润（规模效益）

### 要避免的常见错误
❌ 在公式中混合市值和企业价值
❌ 使用不同的时间段作为分子和分母（LTM 与季度）
❌ 将数字硬编码到公式中而不是单元格引用中
❌ **硬编码输入，没有引用来源或解释假设的单元格注释**
❌ 缺少 SEC 文件或数据源的超链接（如果有）
❌ 包含太多没有明确目的的指标
❌ 包括非可比公司（不同商业模式）
❌ 使用过时的数据而不披露
❌ 错误计算百分比平均值（应该是中位数）

## 第 7 部分：工作流程和实用技巧

### 分步过程
1. **建立结构**（30 分钟）
   - 创建所有标题
   - 设置单元格格式（蓝色表示输入，黑色表示公式）
   - 锁定单位和日期参考

2. **收集数据**（60-90 分钟）
   - 从主要来源获取（S&P Kensho MCP、FactSet MCP、Daloopa MCP（如果有）；否则为 Bloomberg、SEC）
   - 输入所有蓝色的原始数字
   - 注释部分的文档来源

3. **构建公式**（30 分钟）
   - 从简单的比率（边距）开始
   - 进展倍数（EV/收入）
   - 添加交叉检查（边距有意义吗？）

4. **添加统计数据**（15 分钟）
   - 复制所有列的公式结构
   - 验证范围是否正确（B7:B9，而不是 B7:B10）
   - 检查四分位数逻辑

5. **质量控制**（30 分钟）
   - 运行健全性检查
   - 验证公式参考
   - 检查#DIV/0！或#REF！错误
   - 与已知基准进行比较

6. **文档**（15 分钟）
   - 完成笔记部分
   - 添加数据源
   - 定义方法
   - 为分析添加日期标记

## 第 10 节：危险信号和警告标志

### 数据质量问题
🚩 时间段不一致（混合季度和年度）
🚩 缺少数据且没有解释
🚩 数据源之间存在显着差异（>10% 方差）

### 估值危险信号
🚩 负 EBITDA 公司按 EBITDA 倍数估值（使用收入倍数）
🚩 市盈率 >100 倍，没有高速增长的故事
🚩 对行业来说没有意义的利润

### 可比性问题
🚩 不同的财政年度结束（导致时间安排问题）
🚩修复单一企业和企业集团
🚩 本质上不同的商业模式被标记为“comps”

**如有疑问，请排除该公司。** 拥有 3 个完美的比较比 6 个有问题的比较好。

### 常见比率公式
```excel
Gross Margin = Gross Profit / Revenue
EBITDA Margin = EBITDA / Revenue
FCF Margin = Free Cash Flow / Revenue
FCF Conversion = FCF / Operating Cash Flow
ROE = Net Income / Shareholders' Equity
ROA = Net Income / Total Assets
Asset Turnover = Revenue / Total Assets
Debt/Equity = Total Debt / Shareholders' Equity
```

## 关键原则总结

1. **结构驱动洞察力** - 正确的标题迫使正确的思考
2. **少即是多** - 5-10 个重要指标胜过 20 个不重要指标
3. **为您的问题选择指标** - 估值分析≠效率分析
4. **统计数据显示模式** - 中位数/四分位数显示高于平均值
5. **透明度胜过复杂性** - 每个人都理解的简单公式
6. **可比性为王** - 排除比强加不良比较更好
7. **记录您的选择** - 在注释部分解释哪些指标以及原因
