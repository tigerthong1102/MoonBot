# 数据可视化

在生成图表、仪表板、地图或数据可视化之前使用此技能。

## 工作流程

1. 确定分析任务：比较、趋势、分布、关系、
   排名、部分到整体、地理位置或状态监控。
2. 选择能够回答该任务的最简单的图表形式。阅读
   `references/choosing-a-form.md`当形态不明显时。
3. 将发现写入标题、副标题、轴标签或直接注释中。
   观众应该知道发生了什么变化，什么是高或低，或者做出了什么决定
   图表支持。
4. 从 `references/palette.md` 中选择颜色，或使用以下命令验证任何自定义调色板
   下面的脚本。
5. 在最终确定设计之前检查`references/anti-patterns.md`。

## 调色板验证

解析相对于该技能主体上方显示的技能基础目录的路径。
不要假设为普通 shell 命令设置了 `$QWEN_SKILL_ROOT`。

运行：

```bash
node <skill-base-directory>/scripts/validate_palette.js '#1d4ed8,#b45309,#166534' --mode light
```

将 `FAIL` 视为所需的调色板更改。仅当以下情况时才将 `WARN` 视为可接受
该图表还使用标签、形状、纹理、排序或其他次要的
编码。

## 标记规则

- 对无序组使用分类调色板；使用顺序或发散
  斜坡仅适用于有序值。
- 当图表的系列数量较少时，优先选择直接标签而不是图例。
- 保持网格线微妙且少于数据标记。
- 避免使用双轴，除非两个系列都有一个明确解释的转换。
- 不要仅依靠颜色来进行关键区分。
- 保持仪表板易于扫描：对齐卡片、使用一致的数字格式、
  并为重要的状态变化保留饱和颜色。
