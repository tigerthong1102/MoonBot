# 创建和编辑 Word 文档

使用可用的 DOCX 工具创建或编辑副本。确认部分和输出路径。在支持的情况下保留样式、表格、页眉、页脚和注释。根据要求使用带有跟踪更改的工具。保存、重新打开并检查标题、文本和表格。当布局很重要时检查渲染的副本。
## 本地文档流程

在已配置 `startupbot-python` 的 Mac 上，使用其中的 `python-docx` 进行常规文档创建和编辑。其他机器应使用已配置的文档工具或已安装的兼容库。编辑前检查源文件，并在副本上工作。除非用户要求修改，否则保留作者的结构和措辞。使用恰当的标题样式、清晰的页边距、真正的表格和一致的排版。如果工具支持，为传递信息的图片添加无障碍描述。

重新打开保存后的文档，检查标题、段落和表格。若有 LibreOffice 等渲染工具，导出为 PDF 并检查页面裁切、表格损坏、空白页和图片错位。对于评论、修订、域或所选库无法可靠编辑的其他元素，使用兼容工具，或说明限制并保留原件。更多上游技术详见 `references/upstream.md`；其中的可选脚本和 npm 包需要单独检查是否可用。
