# 股票研究收益更新

根据机构标准（摩根大通、高盛、摩根士丹利格式），创建专业的**收益更新报告**，分析已覆盖公司的季度业绩。

**主要特征：**
- **长度**：8-12 页
- **字数**：3,000-5,000 字
- **表格**：1-3 个汇总表（不全面）
- **数字**：8-12 图表
- **周转**：1-2 天（收益后 24-48 小时内）
- **受众**：已经熟悉公司的客户
- **焦点**：新内容 - 失败/失败、更新的估计、论文影响
- **字体**：通篇使用 Times New Roman（除非用户另有指定）

## 何时使用

当用户请求时使用：
- “为 [公司] 2024 年第 3 季度创建收益更新”
- “分析[公司]的季度业绩”
- “[公司]的盈利报告”
- “[公司] 第一季度/第二季度/第三季度/第四季度更新”

**如果出现以下情况，请勿使用：**
- 用户请求“启动报告”→使用不同的技能
- 用户请求“Flash Note”或“Quick Take” → 不同的格式
- 公司尚未涵盖 → 需要先启动

## 关键要求

### 1. 速度和及时性
- 财报发布后 24-48 小时内发布
- 只关注新信息
- 不要广泛重复公司背景

### 2. 击败/错过分析
- 领导公司是否超出或低于预期
- 量化差异（例如，“收入超出 1.2 亿美元或 3%”）
- 解释为什么结果与预期不同

### 3.摘要格式
- 将表格保留为 1-3（仅摘要，不全面）
- 没有完整的损益表/现金流量/资产负债表（只有关键指标）
- 假设读者已经看到启动报告

### 4. 引文和来源归属 ⭐⭐⭐ 强制

**关键**：正确引用具有特定来源和可点击超链接的所有数据。

**在每个图和表中包含带有可点击链接的具体引文：**

```
Source: Q3 2024 10-Q filed November 8, 2024; Company earnings release
        [Hyperlink "10-Q" to: https://www.sec.gov/cgi-bin/viewer?accession=...]
        [Hyperlink "earnings release" to: https://investor.company.com/news/q3-2024]
```

**超链接在 WORD 中应如何显示：**
- 文档名称显示为蓝色、带下划线的可点击链接
- 读者可以Ctrl+点击直接开源
- 非纯文本 URL - 带显示文本的格式化超链接

**所需来源清单：**

在每次收益更新中引用：
- ✅ 收益发布（带有日期和 URL）
- ✅ 10-Q 归档（包含归档日期和 EDGAR 链接）
- ✅ 财报电话会议记录（带日期）
- ✅ 投资者介绍/补充材料（如果有）
- ✅ 共识估计来源（Bloomberg/FactSet/等，带日期）
- ✅ 事先指导（来自上一季度的材料）

**带有可点击超链接的参考部分：**

在报告末尾添加“来源”部分：

```
SOURCES & REFERENCES

Earnings Materials (Q3 2024):
• Earnings Release (November 7, 2024)
  [Hyperlink entire line to: https://investor.company.com/news/q3-2024-earnings]

• Form 10-Q (Filed November 8, 2024)
  [Hyperlink to: https://www.sec.gov/cgi-bin/viewer?accession=...]

• Earnings Call Transcript (November 7, 2024)
  [Hyperlink to: https://seekingalpha.com/article/...]

• Investor Presentation (November 7, 2024)
  [Hyperlink to: https://investor.company.com/presentations/q3-2024.pdf]
```

**验证清单：**
- [ ] 每个数字都有来源以及特定文件和日期
- [ ] 每个表格都有来源和文档参考
- [ ] 失败/失败分析引用了带有日期的共识来源
- [ ] 指南变更引用当前和之前的指南来源
- [ ] 关键统计数据有脚注
- [ ] 来源部分列出了所有带有 URL 的材料
- [ ] 所有 URL 都是可点击的超链接（不是纯文本）
- [ ] 所有 SEC 文件均链接至 EDGAR 查看器

### 5. 更新的估计
- 根据结果更新远期估计
- 清楚地显示旧的与新的估计
- 解释发生了什么变化以及原因

## 高级工作流程

收益更新过程分为 5 个阶段：

### 第 1 阶段：数据收集（30-60 分钟）

**🚨🚨🚨 严重：训练数据已过时 🚨🚨🚨**

**开始之前 - 按顺序完成以下 4 个步骤：**
1. **检查今天的日期** - 写下当前日期
2. **搜索最新** - 使用网络搜索：“[公司]最新收益结果”
3. **验证日期** - 确认收益发布是在过去 3 个月内
4. **检查转录日期** - 验证转录日期与发布日期相符

**常见错误**：使用训练数据中过时的财报电话，而不是搜索最新数据。

**要求：**
- ✅ 搜索最新收益 - 不要依赖训练数据
- ✅ 写下今天的日期和找到的发布日期
- ✅ 验证发布日期是在今天之后的 3 个月内
- ✅ 验证成绩单日期是否与发布日期相符
- ✅ 如果日期不匹配或已过时（> 3 个月），请重新搜索

**请参阅 [references/workflow.md](references/workflow.md)** 了解详细的搜索过程和验证步骤。

### 第 2 阶段：分析（2-3 小时）
- 每个关键指标的节拍/缺失分析
- 细分市场/地域/产品细分
- 保证金和指导分析
- 更新财务模型和估计

**详细分析框架请参见[references/workflow.md](references/workflow.md)**。

### 第 3 阶段：图表生成（1-2 小时）
创建 8-12 个图表，重点关注季度趋势和新动态：
- 季度收入进展
- 季度每股收益进展
- 季度利润率趋势
- 按细分市场/地区划分的收入
- 关键运营指标
- 失败/失败总结
- 估计修订
- 估值图表

**请参阅 [references/workflow.md](references/workflow.md)** 了解图表规范。

### 第 4 阶段：创建报告（2-3 小时）
创建具有特定结构的 8-12 页 DOCX 报告。

**请参阅 [references/report-struct.md](references/report-structure.md)** 了解完整的逐页模板和格式要求。

**高层结构：**
- 第 1 页：带有评级和目标价格的收益摘要
- 第 2-3 页：详细结果分析
- 第 4-5 页：关键指标和指南
- 第 6-7 页：更新的投资论文
- 第 8-10 页：估价和估算
- 第 11-12 页：附录（可选）

### 第 5 阶段：质量检查和交付（30 分钟）
在交付前验证内容、格式、准确性和及时性。

**请参阅 [references/best-practices.md](references/best-practices.md)** 了解质量检查表和要避免的常见错误。

## 输出规格

**主要交付成果**：DOCX 报告（8-12 页）
**文件名**：`[Company]_Q[Quarter]_[Year]_Earnings_Update.docx`
**示例**：`Nike_Q2_FY24_Earnings_Update.docx`

**内容：**
- 第 1 页：评级摘要、目标价格、要点
- 第 2-3 页：详细结果分析
- 第 4-5 页：关键指标和指导
- 第 6-7 页：更新的论文评估
- 第 8-10 页：估价和估算
- 第 11-12 页：附录（可选）
- 8-12 嵌入图表
- 1-3汇总表
- 带有可点击超链接的完整来源部分

**可选交付成果**：XLS 模型更新（收益更新可选）
