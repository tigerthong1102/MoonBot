# 文档（v1）

> **先决条件：** 阅读 `../gws-shared/SKILL.md` 了解身份验证、全局标志和安全规则。如果缺少，请运行 `gws generate-skills` 创建它。

```bash
gws docs <resource> <method> [flags]
```

## 辅助命令

| 命令 | 说明 |
|---------|-------------|
| `+write` | 将文本附加到文档 |

## API资源

### 文件

  - `batchUpdate` — 对文档应用一项或多项更新。每个请求在应用之前都会经过验证。如果任何请求无效，则整个请求将失败并且不会应用任何内容。有些请求会得到回复，为您提供一些有关如何应用它们的信息。其他请求不需要返回信息；这些都返回一个空回复。回复的顺序与请求的顺序一致。
  - `create` — 使用请求中给出的标题创建空白文档。请求中的其他字段（包括任何提供的内容）将被忽略。返回创建的文档。
  - `get` — 获取指定文档的最新版本。

## 发现命令

在调用任何 API 方法之前，请检查它：

```bash
# Browse resources and methods
gws docs --help

# Inspect a method's required params, types, and defaults
gws schema docs.<resource>.<method>
```

使用 `gws schema` 输出来构建 `--params` 和 `--json` 标志。
