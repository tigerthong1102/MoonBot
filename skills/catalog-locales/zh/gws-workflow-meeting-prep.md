# 工作流程+会议准备

> **先决条件：** 阅读 `../gws-shared/SKILL.md` 了解身份验证、全局标志和安全规则。如果缺少，请运行 `gws generate-skills` 创建它。

准备下一次会议：议程、与会者和链接文档

## 用途

```bash
gws workflow +meeting-prep
```

## 旗帜

| 标志 | 必需 | 默认 | 描述 |
|------|----------|---------|-------------|
| `--calendar` | — | 主要 | 日历 ID（默认值：主要）|
| `--format` | — | — | 输出格式：json（默认）、table、yaml、csv |

## 示例

```bash
gws workflow +meeting-prep
gws workflow +meeting-prep --calendar Work
```

## 温馨提示

- 只读——从不修改数据。
- 显示下一个即将举行的活动以及与会者和说明。
