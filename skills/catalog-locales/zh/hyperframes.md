# 使用本地 HyperFrame 构建视频

使用现有的 HyperFrames 安装从原始或授权媒体构建视频。就持续时间、宽高比、脚本和输出路径达成一致。使用本地 CLI 帮助确认特定于版本的命令。 Lint、检查和预览构图并检查过渡周围的帧。查看预览后渲染本地 MP4。在 CLI 环境中设置 HYPERFRAMES_NO_TELEMETRY=1。使用已安装并清除的字体进行输出。
