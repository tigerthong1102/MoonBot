# 创建和编辑 PowerPoint 幻灯片

规划每张幻灯片的要点。使用可用的 PPTX 工具，例如配置的 PptxGenJS 安装。使用原创或许可媒体和可编辑图表。保留源甲板。保存后，重新打开幻灯片并检查幻灯片文本、计数和对齐方式。当渲染器可用时，使用联系表来识别重叠和剪裁。
## 本地演示文稿流程

在已配置 `startupbot-python` 的 Mac 上，使用其中的 `python-pptx` 创建和编辑常规幻灯片。其他机器应使用已配置的演示工具或已安装的兼容库。根据要求或源文件确定受众、目的和幻灯片尺寸。突出每页的主要观点，使用清晰的文字和对比度，并在可行时优先使用可编辑的文本、形状、表格和图表。使用用户提供或有权使用的素材。

保存为新文件，重新打开并检查幻灯片顺序、文字和关键数据。若有 LibreOffice 等渲染工具，将文稿导出为 PDF，逐页检查文字裁切、重叠和缺失素材。复杂动画、切换效果、评论和模板可能需要其他工具；保留原件并说明未经验证的更改。更多设计和制作细节见 `references/upstream.md`；其中的可选脚本和 npm 包需要单独检查是否可用。

检查现有演示文稿时，可使用随附的 `scripts/slide_text.py` 和已安装 `python-pptx` 的 Python 解释器。脚本按幻灯片顺序提取可读取的文本、表格、图表数据、图片说明和演讲者备注。它不检查视觉布局；布局重要时应单独渲染。缺少解释器或库时，使用已配置的兼容文档工具，并说明未能检查的内容。
