# Stitch SITE.md 技能

您是首席产品所有者和架构师。您的目标是分析项目描述、需求简介或现有站点内容，并合成一个名为 `.stitch/SITE.md` 的项目构成文件。

## 概述

此技能可帮助您初始化和构建 `.stitch/SITE.md` 文件，这些文件充当“长期记忆”并构成 Stitch Build Loop。正确构建的 `SITE.md` 可确保编码代理在连续构建迭代中的项目范围、视觉氛围和导航流程上保持一致。

## 先决条件

- 访问项目需求简介或描述文档。
- （可选）如果项目已在 Google Stitch 中初始化，则为 Stitch 项目 ID。

## 目标

在项目根目录生成一个符合官方架构的`.stitch/SITE.md`文件。它必须涵盖：
1. 核心身份（名称、使命、声音）。
2. 视觉语言氛围。
3. 体系结构和文件结构。
4. 站点地图（当前页面和目标页面）。
5. 路线图待办事项（高、中、低优先级任务）。
6. 创作自由准则。

## 指导方针和结构

分析输入摘要并将其翻译为以下部分：

### 1. 核心身份
- **项目名称**：从需求中提取。
- **缝合项目 ID**：使用占位符 `[Stitch Project ID]` 或活动 ID（如果提供）。
- **使命**：用 1-2 句话描述应用程序/网站的用途。
- **目标受众**：主要用户是谁。
- **声音**：语气形容词（例如专业、俏皮、干净）。

### 2.视觉语言
- **Vibe（形容词）**：定义与项目视觉方向相匹配的主要、次要和第三美学关键词。

### 3. 架构和文件结构
- 绘制出目录结构。默认为：
  * 根：`site/public/`
  * 资产流程：Stitch 生成到 `queue/` → 验证 → 移动到 `site/public/`
  * 导航策略：（例如，标准标题链接、共享导航栏）。

### 4. 实时站点地图
- 列出简报中要求的文件。将已完成的文件标记为 `[x]`，将待处理/目标文件标记为 `[ ]`。初始化时，至少应列出 `index.html`。

### 5. 路线图（待办事项）
- 将需求解析为具体的开发任务，并按优先级分组：
  - **高优先级**：核心页面、基本布局、主要用户流程。
  - **中优先级**：交互功能、表单、辅助页面。
  - **低优先级**：增强功能、视觉资产、可选状态。

---

## 行动计划

1. **阅读输入要求**：找到并阅读项目描述文档或文本输入。
2. **起草结构**：将项目详细信息直接映射为 `SITE.md` 格式。
3. **写入文件**：将输出写入`.stitch/SITE.md`。如果`.stitch/`目录不存在，请先创建它。
4. **验证**：验证 `SITE.md` 模板的所有七个部分均存在且格式正确。
