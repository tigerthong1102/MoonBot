# 论文跟踪器

## 工作流程

### 第 1 步：定义或加载论文

如果创建新论文：
- **公司**：名称和股票代码
- **位置**：多头或空头
- **论文陈述**：1-2 句话核心论文（例如，“长期 ACME — 随着组合转向软件，定价能力 + 运营杠杆的利润扩张”）
- **关键支柱**：3-5 个支持论点
- **主要风险**：3-5 个可能导致论文无效的风险
- **催化剂**：可能证明/反驳该论点的即将发生的事件（收益、产品发布、监管决策）
- **目标价格/估值**：如果论文得以实现，它的价值是多少
- **止损触发**：什么会让你退出

如果更新现有论文，请向用户询问新的数据点或发展。

### 第2步：更新日志

对于每个新数据点或发展：

- **日期**：发生这种情况的时间
- **数据点**：发生了什么变化（盈利增长、管理层离职、竞争对手变动等）
- **论文影响**：这是否会加强、削弱或抵消某个特定支柱？
- **动作**：无变化/增加位置/修剪/退出
- **更新信念**：高/中/低

### 第三步：论文记分卡

维护运行记分卡：

| 支柱 | 原始预期 | 当前状态 | 趋势 |
|--------|---------------------|----------------|-------|
| 收入增长 >20% | 步入正轨 | 第三季度增长 22% | 稳定 |
| 利润率扩张 | 落后于 | 利润率同比持平 | 关于 |
| 新品发布 | 待定 | 推迟到第二季度 | 观看 |

### 第 4 步：催化剂日历

追踪即将到来的催化剂：

| 日期 | 事件 | 预期影响 | 注释 |
|------|-------|-----------------|-------|
| | | | |

### 第五步：输出

论文摘要适合：
- 早会讨论
- 投资组合审查
- 风险委员会介绍

格式：简明的 Markdown 或包含记分卡、最近更新和当前信念级别的 Word 文档。

## 重要提示

- 论文应该是可证伪的——如果没有什么可以反驳它，那么它就不是论文
- 像确认证据一样严格追踪否定证据
- 至少每季度回顾一次论文，即使没有发生任何戏剧性的事情
- 如果用户管理多个职位，请提供完整的投资组合论文审查
- 以结构化格式存储论文数据，以便跨会话引用
